# 音乐播放动效 · 4 个提示词

对应抖音视频：4个音乐播放动效，让播放页高级起来

不想装 skill？直接复制下面的提示词发给 AI 编程工具（Claude Code / Codex / Cursor 等）就能用。

每个都附了"常见写法"，对比一下就知道差在哪：只说"切换一下"，AI 多半只给你换个图标。

---

## 01 黑胶封面旋转（Vinyl Spin）
常见写法：做个音乐播放页，点播放按钮切换播放和暂停 → 只换个图标，唱片一动不动

```
做一个音乐播放页：点播放后，黑胶唱片从专辑封面背后滑出来，持续匀速旋转，约 6 秒一圈，唱针轻轻落到唱片上；暂停时唱片带阻尼慢慢停住、唱针抬起，再点播放接着转。
```

## 02 歌词逐行高亮（Lyrics Sync）
常见写法：做个歌词页面，唱到哪句就高亮哪句 → 只换字色，高亮硬跳行，列表不跟随

```
做一个歌词页：当前唱到的那一行背后出现一块高亮色块，换行时色块平滑变形、上下滑动包住下一行，歌词列表同时自动滚动，让当前行始终停在屏幕中间，一句接一句跟着节奏走。
```

## 03 上滑切歌（Track Swipe）
常见写法：做个播放页，上滑切换到下一首歌 → 拖动时不动，松手瞬间硬切

```
做一个上滑切歌：手指按住专辑封面往上拖，封面实时跟手移动、缩小并轻微旋转，下一首封面从底部同步升上来；松手超过一定距离，就用带过冲的弹性动画把当前封面甩出去、下一首放大归位，没超过就弹回原位，歌名和进度条跟着交叉淡入。
```

## 04 播放页下滑收起（Player Collapse）
常见写法：做个播放页，往下滑就能收起回到列表 → 松手才整页下滑，背景不缩放

```
做一个全屏播放页下滑收起：手指按住页面向下拖，整页实时跟手下移，背后的音乐库从 0.92 倍放大到 1 倍，压暗的遮罩慢慢消失；松手超过一定距离，页面带弹簧减速滑出屏幕，露出音乐库，底部出现迷你播放条；没超过就弹回原位。
```

---

装了 skill 的话，直接说"用 ui-motion 做一个黑胶封面旋转"即可，AI 会按动效库里的完整参数实现。
