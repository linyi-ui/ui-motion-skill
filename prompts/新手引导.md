# 新手引导 · 4 个提示词

对应抖音视频：4个新手引导，让用户一眼知道点哪

不想装 skill？直接复制下面的提示词发给 AI 编程工具（Claude Code / Codex / Cursor 等）就能用。

每个都附了"常见写法"，对比一下就知道差在哪：只说"做个引导"，AI 多半只会在屏幕中间放一个框。

---

## 01 聚光灯功能引导（Spotlight Coach Mark）
常见写法：做一个记账 App，第一次打开时给新用户做一个功能引导 → 引导是居中弹框，不指按钮也不滑；点下一步直接跳

```
做一个记账 App 首次打开的聚光灯功能引导，像舞台上一束追光照着你该点的地方：整个页面盖一层约 70% 的黑色遮罩，只在"记一笔"按钮那里挖一个圆角镂空，镂空边缘一圈慢慢呼吸的细白描边；旁边弹出白色说明气泡（标题 + 一句说明 + "1/3" + "下一步"按钮），气泡带小三角指向按钮，从小弹到正常大小；点"下一步"时镂空平滑滑到下一个按钮，并变成它的形状和大小（约 400ms，不要先消失再出现），气泡跟着换位置和文字；共 3 步，最后一步按钮变"知道了"，点后遮罩淡出；右上角有"跳过"；按 390×844 手机尺寸。
```

## 02 欢迎页滑动引导（Onboarding Carousel）
常见写法：做一个 App 的欢迎引导页，3 页左右滑动，介绍 App 功能 → 整页一起平移，插画文字没层次；圆点到点才跳

```
做一个 App 的3 页欢迎引导页，像翻一本有层次的立体绘本：左右滑动切换，手指拖到哪页面就跟到哪，松手超过三分之一或甩得快就翻到下一页，否则弹回；每页的插画和文字移动速度不同（插画慢、标题快，有前后层次感），插画同时有一点缩放和淡入；底部小圆点指示器，当前页的圆点被拉长成胶囊，滑动时跟着手指一起伸缩过渡；最后一页底部的"开始使用"按钮从下面弹上来，前两页右上角显示"跳过"；按 390×844 手机尺寸。
```

## 03 空状态引导（Empty State CTA）
常见写法：做一个待办 App，列表为空时显示空状态提示，可以添加任务 → 新待办直接冒出来，空状态一闪就没

```
做一个待办 App 的空状态引导，像空桌子上有人指着说"从这开始"：列表没东西时，中间一张插画轻轻上下浮动 + 标题"还没有待办" + 一句说明，下面一条弯曲的虚线箭头指向右下角的"+"按钮，"+"按钮每隔几秒轻轻弹一下提醒点击；点"+"后底部弹出一行输入框，点"添加"后，这条待办从"+"按钮的位置飞出来落进列表（带一点回弹），空状态插画和箭头缩小淡出，列表顶部出现"第一条已添加"的小提示；按 390×844 手机尺寸。
```

## 04 权限请求前说明（Permission Pre-prompt）
常见写法：做一个打卡 App，需要向用户申请通知权限 → 不说明就直接弹系统权限框

```
做一个打卡 App 开启通知前的说明卡，像先敲门打个招呼再进屋：用户第一次打卡成功后，从底部弹起一张圆角说明卡（带回弹），上面一个轻轻晃动的铃铛图标 + 标题"每天 8 点提醒你打卡" + 一句好处说明 + 一条锁屏通知的小预览（像真的通知一样滑进来）；两个按钮"好的，提醒我"和"以后再说"；点"好的"后说明卡收下去，再弹出系统的通知权限请求（演示时用一个仿 iOS 的系统弹框代替，淡入并轻微放大）；点"以后再说"只收起卡片，不弹系统框；按 390×844 手机尺寸。
```
