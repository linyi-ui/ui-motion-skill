# 发帖动效 · 原片复刻（POST / COMPOSE / SHARE）

这一版六条提示词全部来自 60fps.design 上的真实 App 录屏（Snapseed / Pool / Threads / Instagram / [untitled] / Unsplash），按原片逐帧复刻，不是按名字自由发挥。

适用范围：社交动态、社区、二手、相册类 App 里的「选图 → 写帖 → 分享 → 成功」链路。

---

## 01 网格切换（Grid Toggle）

相册页三列变两列，所有卡片同时缩放重排、弹簧到位，全程不跳裁。

做一个相册页的「网格切换」交互，手机竖屏 390×844，深色。
顶部「相册」标题，右上角 30×30 四宫格图标。
默认 3 列网格：6 张照片，每格 128×172、圆角 7、间距 3，从 y=100 起。
点图标：所有照片在 0.58 秒内同时缩放并挪位到 2 列（每格 193×243、间距 3.5），用弹簧曲线，末尾轻微过冲再回正，不能跳裁、闪白或中途消失；图标按下缩到 0.84 倍再回弹。
再点一次：同样用弹簧回到 3 列。
照片要真实内容，不许纯色块。

## 02 点开大图（Card Morph）

相册网格点一张，从原格弹成全屏，下滑跟手、松手精确缩回原格。

做一个相册页的「点开大图」交互，手机竖屏 390×844，深色。
3 列网格，12 张照片，每格 126×168、圆角 7、间距 3。
点第 2 行第 2 列：这张照片从它原来的格子在 0.5 秒内弹成全屏（宽 390、高 760、y=44、圆角 7 收到 0），其余照片同时淡到很暗，不要瞬间消失；大图底部渐变压暗 + 「18:32 · 海边落日」，顶部 96×5 关闭把手。
按住大图下滑：1:1 跟手；松手后 0.47 秒缩回原来那一格，位置和尺寸精确回到起点，其余照片同步恢复。
不要新开一页或弹窗，必须是同一张照片变形。

## 03 发帖面板（Compose Sheet）

点写帖，「新动态」面板与键盘同一个时钟一起升起；点投票选项撑开、工具栏让位。

做一个「新动态」发帖面板，手机竖屏 390×844，深色。
首页信息流两条动态 + 底部深色底栏，中间 44×44 强调色写帖按钮。
点按钮：遮罩压暗 55%，面板和键盘同时从底部升起——面板在上（顶边 y=88，圆角 22，含把手和「取消 / 新动态 / 发布」），键盘贴底（顶边 y=520，含 44px 候选栏 + 三行字母 + 空格行）；两块同一个时钟一起上，用时 0.52 秒，末尾轻微弹簧。
面板内容：作者行、输入区「有什么新鲜事？」、工具栏五个图标（图片 / GIF / 投票 / 话题 / @）。
点「投票」：选项区 0.4 秒从 0 撑开，两个选项框（高 44、圆角 12）一前一后淡入 + 弹簧（第二个晚 0.06 秒），工具栏被推下 66px 让位；再点收起。
强调色 #FFC83D。

## 04 头像写备注（Add Note）

点头像小胶囊，头像从原位长大居中写备注，收起后落成头像上的小胶囊。

做一个「头像写备注」交互，手机竖屏 390×844，深色。
一条动态：左上角 34×34 圆头像，头像上方一颗「分享想法」小胶囊，下面是文字和大图。
点胶囊：
1）头像从原位置在 0.5 秒内长到 150×150 并挪到屏幕中央（y=318），用弹簧；背景压暗 62%。
2）头像上方 62px 处出现 250×46 气泡（圆角 16、半透明白底），从 0.9 倍弹到 1 倍，文字「添加备注…」。
3）键盘升到顶边 y=520，用时 0.42 秒。
4）逐字打出「海边风很大」，1 秒打完，右侧出现强调色「分享」。
5）点分享：全部收起 0.56 秒，头像回到 34×34 原位，文字落成头像上方小胶囊（高 26、圆角 13），从 0.9 倍弹到 1 倍。
强调色 #FF6B5B。

## 05 链接分享面板（Share Expand）

点开启，按钮收成转圈，面板展开，平面卡立成 3D 斜卡，三行选项逐行弹入。

做一个「链接分享」底部面板，手机竖屏 390×844，深色。
顶部「海边落日 / 12 张照片」，底部面板（顶边 520、高 324、圆角 24），里面一张 240×150 粉紫渐变卡，底部强调色「开启链接分享」按钮。
点按钮：按钮收成 48×48 圆形转圈（0.42 秒，边收边转），持续旋转。
面板 0.54 秒向上展开（顶边 520→144、高度 324→700，弹簧）；平面渐变卡立起来变成 3D 斜卡（perspective 900px、rotateX 9°、rotateY -17°、放大 1.12 倍、0.6 秒弹簧），卡面每 1.6 秒扫一道斜向高光。
展开后三行逐行弹入（每行晚 0.07 秒、单行 0.3 秒，从下往上 16px）：「链接权限 / 任何人可查看」+ 右侧开关、「复制链接」、红色「设为私密」。
点「设为私密」弹确认框（「关闭链接分享？」+ 取消/确定），点确定面板收回初始高度。
强调色 #9D8CFF。

## 06 发布成功彩带（Submit Confetti）

点提交，成功弹窗弹出，54 片彩带从顶部飘落，大小/转速/摆动各不相同。

做一个「发布成功」提交交互，手机竖屏 390×844，深色。
顶部「提交作品」，一张大图、「标题 / 海边落日，今天风很大」、「精选标签」三个胶囊，底部强调色「提交」按钮。
点提交：按钮压到 0.95 倍再回弹；0.34 秒后弹出成功弹窗（遮罩压暗 55%、296×210 卡片、圆角 22，从 0.82 倍弹簧到 1 倍），内容是浅绿圆底 + 勾、「提交成功」、「感谢你的分享，作品正在审核中」、底部「完成」。
同时彩带从屏幕顶部飘落：共 54 片圆角矩形，8 种颜色，每片宽 7-13、高 10-20 互不相同，起始 y 在 -40 到 -400 错开，下落 150-340 px/s 且带 40 px/s² 加速，横向各有 14-40px 左右摆动（频率不同），旋转 -520 到 +520 度/秒各不相同。
彩带 2.7 秒后逐个淡出，3.5 秒消失；弹窗保留。
不许所有彩带同样大小、同样速度（那样像一堆方块一起掉）。
