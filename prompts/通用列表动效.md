# 通用列表与空状态动效（SWIPE / PULL / PINCH / EMPTY）

这一版四条提示词全部来自 60fps.design 上的真实 App 录屏（Clear / X），按原片逐帧复刻；界面细节按真实上线的 App 做（到期时间、彩色标签、iOS 键盘、目录清单、主菜单），不是演示色块。

适用范围：几乎每个 App 都有的列表页与空状态页——待办、记账、收藏、消息、订单、设置。

---
## 01 右滑完成（Swipe to Check）

列表行右滑露出绿底和勾，松手划线、整行滑走，下面的行补位，计数 +1。

（要点：前景行跟着手指走，绿底和勾固定不动；勾必须用描边一笔画出来，不是缩放弹出。）

做一个待办清单页，手机竖屏 390×844，深色底 #141114。
顶部「Welcome to Clear」+ 一行灰色说明「This is an example list」，右上角一个日期胶囊「11月21日 周五」。
下面六条彩色任务行：颜色从 #F2483C 到 #F5C94A 依次渐变，每条高 78、行距 6、整行铺满屏宽；每行左侧是任务标题 15.5px 加粗，下面一行小字是到期时间，右侧一个圆角小标签（家人 / 工作 / 生活 / 健康 / 杂事 / 阅读）。
左下角一行灰色提示「Swipe right to check this off」，右下角一个红色圆角按钮 #E8455F，里面两行小字「完成 3 项 / 勾选 3 项」；底部一行统计「12 已完成 · 共 12 项 · 今天还剩 5 项」。
交互：手指按住第三条往右拖，这一行跟着手指整体右移，左侧绿底 #57C84A 被揭开、一个白色勾用描边一笔一笔画出来（0.22 秒画完，不是缩放弹入）。
松手：这一行文字上划一道 150px 横线、亮度降到 0.76，继续往右滑出屏幕；下面三行错峰向上补位（每行比上一行晚 0.06 秒，弹簧缓动带 6% 过冲）；底部计数从 12 跳到 13。
不要整行连着绿底一起移动。

## 02 下拉新增（Pull to Add）

在最上面往下拉，第一行被纵向拉长，上面让出一块输入框，拉过阈值吸附，整块 iOS 键盘同时升起。

（要点：键盘和输入框同一个时钟起来；列表可视区跟着键盘顶边裁切；拉长时行内文字同步拉伸。）

做一个待办清单页，手机竖屏 390×844，深色底 #141114。
顶部「Welcome to Clear」+ 灰色说明 + 右上角日期胶囊；下面六条彩色任务行（高 74、行距 6），每行带标题、到期时间和右侧标签；右下角红色圆角按钮。
交互：手指在最上面那一条往下拉，这一条纵向拉长（最高到原高的 1.55 倍，行内文字同步略微拉伸，像橡皮筋），它上面让出一块红色 #F2483C 输入框，里面写「添加事项…」，拖过 40px 后文字变深色并出现一根闪烁光标。
松手：拉过约 118px 吸附到固定位置（0.22 秒到位，末尾轻微回弹）；同一时刻底部升起一块真实 iOS 键盘（高 336px：44px 候选栏 + 三行 QWERTY 字母 + Shift/删除 + 空格/换行/语音），列表可视区跟着键盘顶边裁切，底部红色按钮和提示一起淡出。
不要先弹键盘再挤列表。

## 03 捏合返回（Pinch to Back）

双指捏合，整页等比缩成上一层列表里的一行；再捏一次，这一层也缩进主菜单。

（要点：整页一起 scale，不是只缩容器外框；缩小中段不能让内容变空壳。）

做一个 Clear 风格待办 App，手机竖屏 390×844，三层结构。
第一层列表页：深蓝底 #0E1520，标题「Welcome to Clear」，下面六条彩色任务行（红到黄渐变），每行带标题和到期时间。
第二层目录页：更深的 #0B111A，标题「My Lists」+「6 个清单 · 共 56 项」，下面六行：每行一个彩色圆点、清单名、右对齐数量、右箭头（Welcome to Clear / Personal / Work / 购物清单 / 旅行准备 / 读书笔记）。
第三层主菜单：灰蓝底 #3E4550，七项带彩色图标：Clear / My Lists / Personalize / Rewards / Shop / Archive / Support。
交互：两个手指（真实触点，外圈加内实心点）在列表页中心向内捏合；整页等比缩小（里面的文字和彩条一起变小，不是只缩外框），圆角从 0 涨到 12，最后落进目录页第一行。
继续：再捏一次，目录页缩小淡出，露出主菜单。两段都弹簧缓动。
不要让内容在缩小时重排。

## 04 空状态形变（Empty State Morph）

空状态的图标在相机、镜头、棒球、地球、四角星芒之间连续变形，稳定后才画出内部细节。

（要点：形状重采样成同样多的锚点后逐点插值；内部细节必须"稳定时淡入、一变形立刻消失"。）

做一个空状态页，手机竖屏 390×844，白底。
顶部 X 风格标签栏：左边 X 标，中间 Design / AI / Tech / Software / Design Tweaker 五个标签（第一个高亮），右边「Add +」。
中间一个 176px 深色线框图标，下面「Explore your interests」「See Tweets that interest you」，再下面一颗黑色圆角按钮「Add Interests」；底部一条 tab 栏（首页 / 搜索 / 通知 / 消息）。
交互：图标无限循环变形，顺序是 相机 → 圆形镜头 → 棒球 → 地球 → 四角星芒 → 回到相机。每个形状重采样成 64 个等弧长锚点后逐点插值，线条平滑过渡；变形时线条略变细、透明度略降，模拟溶解重绘；到位稳定后才淡入该形状的内部细节（相机快门键 / 镜头内圈 / 棒球两条缝线 / 地球经纬线），一变形就立刻消失。
参数：线宽 2.6、图标 176px 居中、每段变形 0.85–1.05 秒、每个形状停 0.5–0.75 秒。节奏要慢，变太快会像加载失败在闪。
