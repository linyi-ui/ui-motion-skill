# 通用列表与空状态动效（SWIPE / PULL / PINCH / EMPTY）

这一版四条提示词全部来自 60fps.design 上的真实 App 录屏（Clear / X），按原片逐帧复刻。

适用范围：几乎每个 App 都有的列表页与空状态页——待办、记账、收藏、消息、订单、设置。

---

## 01 右滑完成（Swipe to Check）

列表行右滑露出绿底和勾，松手划线、整行滑走，下面的行补位，计数 +1。

做一个待办清单页，手机竖屏 390×844，深色底 #141114、暖色文字。
顶部标题「Welcome to Clear」+ 一行灰色说明「This is an example list」，下面六条彩色横条任务，颜色从 #F2483C 到 #F5C94A 依次渐变，每条高 78、行距 6、整行铺满屏宽。
交互：手指按住第三条往右拖，被拖的那一行整体跟着手指右移（前景彩条移动，左侧的绿底和勾固定不动），左边露出绿底 #57C84A 和一个白色大勾；勾在露出来的第一瞬间从 0.5 倍弹到 1 倍。
松手：这一行文字上划一道 130px 的横线、整行亮度降到 0.76，继续往右滑出屏幕；它下面所有行错峰向上补位（每行比上一行晚约 0.06 秒，用弹簧缓动带轻微过冲）；底部「已完成」计数从 12 跳到 13。
不要整行连着绿底一起移动——绿底是被"揭开"的背景，不是跟着手指走的东西。

## 02 下拉新增（Pull to Add）

在最上面往下拉，第一行被纵向拉长，上面让出一块输入框，拉过阈值吸附，键盘同时升起。

做一个待办清单页，手机竖屏 390×844，深色底 #141114。
顶部「Today」+「7 项待办 · 2 项已完成」，下面七条彩色横条任务（高 74、行距 6）。
交互：手指在最上面那一条往下拉，这一条被纵向拉长（最高到原高的 1.55 倍，越拉越像橡皮筋），它上面让出一块红色 #F2483C 输入框，框里写「添加事项…」，拖过 40px 后文字变深色并出现一根闪烁光标。
松手：拉过约 120px 就吸附到固定位置（吸附后再走 0.22 秒，末尾轻微回弹），输入框停成可编辑的新行；同一时刻键盘从屏幕底部升起（约 0.44 秒），列表可视区跟着键盘顶边上移，多余内容被裁掉而不是露出一截。
不要先弹键盘再挤列表——键盘和输入框必须是同一个时钟起来的。

## 03 捏合返回（Pinch to Back）

双指捏合，整页等比缩成上一层列表里的一行；再捏一次，这一层也缩进主菜单。

做一个 Clear 风格的待办 App，手机竖屏 390×844，三层：
第一层列表页：深蓝底 #0E1520，顶部「Welcome to Clear」和一行灰色说明，下面六条彩色横条（红到黄渐变），底部一行小字。
第二层目录页：更深的底 #0B111A，标题「My Lists」，下面第一行是「Welcome to Clear」+「12 项」，再下面 Personal / Work / 购物清单 / 旅行准备 四行。
第三层主菜单：灰蓝底 #3E4550，七行：Clear / My Lists / Personalize / Rewards / Shop / Archive / Support。
交互：两个手指在列表页中心向内捏合，两个白色细圈夹点随手指靠拢；整页等比缩小（整页一起缩，里面的内容也跟着变小，不是只缩外框），圆角从 0 涨到 12，最后落进目录页变成一行「Welcome to Clear」。
继续：再捏一次，目录页缩小并淡出，露出最外面的主菜单。两段都用弹簧缓动，缩小的同时内容保持清晰可读。
不要让内容在缩小时重排——整页 scale 缩小才对；只缩容器外框会让内容看起来像贴纸。

## 04 空状态形变（Empty State Morph）

空状态的图标自己在几个形状之间连续变形，线条平滑过渡，一个接一个循环。

做一个空状态页，手机竖屏 390×844，白底。
顶部一行 X 风格标签栏，中间一个约 100px 的深色线框图标，下面「Explore your interests」「See Tweets that interest you」，再下面一颗黑色圆角按钮「Add Interests」。
交互：图标无限循环变形，顺序是 相机 → 圆形镜头 → 六边形 → 五边形 → 菱形 → 四角星芒 → 回到相机。每个形状重采样成同样多的锚点后逐点插值，线条连续过渡，不要闪切、不要突然换图。
参数：线宽 2.4、图标 100px 居中、每段变形 0.85–1.05 秒、每个形状到位后停 0.5–0.75 秒。
节奏要慢——变太快会像加载失败在闪，不像在"呼吸"。
