# AI 对话动效 · 8 个提示词

对应抖音视频：8个AI对话动效，让App像在聊天

不想装 skill？直接复制下面的提示词发给 AI 编程工具（Claude Code / Codex / Cursor 等）就能用。

每个都附了"常见写法"，对比一下就知道差在哪：只说"做个 AI 语音页"，AI 多半只会摆一颗不动的球。

---

## 01 语音球呼吸（Voice Orb）

常见写法：球直接出现，边缘不动，看着像一张贴图在放大缩小

```
做一个手机 AI 语音模式页：浅底，顶部「语音模式」。中间一颗 170px 蓝紫圆球，从 0.22 倍弹性长到 1 倍；之后边缘持续不规则起伏（四角圆角各自循环变化，周期 2.4 秒），蓝紫青三团渐变在里面错相转动。球下 9 根声波柱随呼吸起伏，再下「正在聆听」，底部 68px 黑色停止键。点停止：球 0.45 秒收缩消失，切到聊天页，标题和 4 条建议卡错峰上浮，底部出现胶囊输入框。
```

## 02 聆听描边（Listening Ring）

常见写法：整条边一起变色，没有沿边缘流动的感觉

```
做一个手机 AI 搜索输入页：白底，顶部图标和品牌名，中间大标题、三张快捷卡，底部 354×56 胶囊输入框（左加号、灰占位、右侧青色麦克风），下面是浅色键盘。点麦克风：输入框描边由灰变七彩圆锥渐变（青→靛→紫→粉→黄），沿外框顺时针持续流动约 0.6 圈/秒，整框呼吸放大 1.2%；麦克风变红，框上方淡入转写卡逐字出字。再点：描边收回，转写收进输入框，右侧变青色发送键。
```

## 03 竖滑档位（Level Slider）

常见写法：档位直接跳，没有拖动过程，滑块只是一根滚动条

```
做一个深色 AI 聊天 App 的档位选择器：黑底，顶部标题、用户气泡，底部输入框和工具栏（含「5.6 标准」小胶囊）。点胶囊：键盘上方滑出 390×222 深色面板，标题 Intelligence，竖排三档（深度思考/标准/极速）配一条竖向轨道和三个圆点，最右一个 26px 蓝色滑块。拖动时滑块沿轨道走并纵向拉长成胶囊（最多 14px），松手弹性吸附到最近档位；选中项变白、圆点变亮，顶部大字同步切换。
```

## 04 面板长高（Sheet Morph）

常见写法：弹层瞬间变高、列表硬切，出现空洞

```
做一个白底 AI 搜索 App 的底部弹层：页面有标题、占位条、引用卡、底部输入框（右侧胶囊「模型 · 标准」）。先滑上 390×300 白色圆角弹层：顶部把手，标题「选择一个模式」，一行「模型 · 标准」下拉行，下面三行选项卡。点下拉行：弹层高度 300 平滑长到 470，内容换成三行模型列表（标准/深度/写作），逐行错峰上浮。点「深度模型」：描边变青绿出现勾，弹层缩回 300，输入框胶囊变「模型 · 深度」。
```

## 05 逐词跟读（Word Sync）

常见写法：整句一起变色，或者高亮跟音频对不上

```
做一个白底语言跟读 App：顶部关闭、「会 话」、菜单，下面细进度条。中间白色圆角卡：左上青色短横线，说话人头像「Léa · 法语」，卡中法语大字，下面中文翻译和音标，底部「点击跟读」和「第 1 句 / 共 3 句」。卡下浅灰历史卡，最下白色播放条（青色暂停键、28 根波形、时间）。点播放：句中单词按顺序逐个变青绿并上浮 2px、放大 4%，前一个复原；一句读完整句淡出上移，下一句从下方 14px 淡入；进度和波形同步。
```

## 06 下拉返回（Pull Back）

常见写法：页面直接消失，没有跟手过程，也没有缩放层次

```
做一个深色 App 详情页下拉返回：底层 2×3 卡片网格。上层全屏详情页：上半 320px 紫黑渐变头图，下面大标题、副标题、正文占位、作者行加关注、三个标签、底部「收藏这篇 · 12.4k」。顶部小字「下拉返回」和把手。按住下拉：整页跟手下移，同时按比例缩到 0.76、四角圆角过渡到 50px，底层网格从 0.95 放大回 1 并变亮。未过阈值松手弹性回位；拉过 340px 松手继续缩小淡出，露出网格。
```

## 07 工具弧（Tools Arc）

常见写法：图标平铺成一排；拖完没有吸附，选中和放大对不上

```
做一个深色 AI App 的工具连接弹层：顶部关闭和「连接工具」，390×620 深色圆角弹层，标题「把工具接进 Grok」和灰色说明；中间一排 64px 图标沿向上凸的弧线排开，中心 1.12 倍带白描边，两侧依次缩到 0.44、变淡、倾斜；下面当前应用名，「已接入」两行列表（Gmail / Google Drive），底部白色胶囊「连接」。左右拖动：整排沿弧滚动（sin 算横向、1-cos 算纵向），中心放大、两侧淡出，选中名同步。点连接变绿「✓ 已连接」。
```

## 08 连接成功（Connect Pulse）

常见写法：光晕一直闪不停，所有文字同时冒出来

```
做一个深色 AI App 连接成功页：背景是压暗的聊天页，上面盖 95% 深色遮罩。中间 96px 圆角卡片放邮件图标，外圈绿光在 0.2~0.9 之间以 3.2 秒周期呼吸并轻微缩放，外侧两圈细绿线以 1.1 秒周期扩散淡出、错开半圈相位。约 2.3 秒后标题「已连接 Gmail」和副标题上浮淡入；接着权限卡从下方 14px 浮起（账号、已授权、三行勾选：读取邮件/提取待办/不发送不删除）；最后灰色小字和「完成」按钮淡入。
```
