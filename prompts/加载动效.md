# 加载动效 · 13 个提示词

对应抖音视频：第04期 4个加载动效

不想装 skill？直接复制下面的提示词发给 AI 编程工具（Claude Code / Codex / Cursor 等）就能用。

每个都附了"常见写法"，对比一下就知道差在哪：只说"加个 loading"，AI 多半做成白屏转圈，内容到了一下子全蹦出来。

---

## 01 骨架屏扫光（Skeleton Shimmer）
常见写法：加载时显示一个转圈 loading → 转半天圈，然后一下子全蹦出来

```
做一个信息流加载：先显示和真实内容形状一样的骨架屏（圆头像、标题条、图片块，尺寸和位置跟真实卡片一致），所有骨架共用一道柔和的斜向光带，每 1.5 秒从左往右扫过；数据到了以后，按头像、标题、图片这些块从上到下每块错开 60ms 依次浮现（淡入 + 上移 8px），骨架同步淡出，整页不跳动、不闪白。
```

## 02 图片模糊到清晰（Blur-up Image）
常见写法：做一个图片墙，加载图片 → 先白一块，图片突然砸下来，版面跳动

```
做一个照片墙：每张图先用同色调的模糊小图占位（主色底 + 20px 高斯模糊），原图加载完后从模糊慢慢变清晰，同时从 1.04 倍轻轻缩回 1 倍，约 500ms；图片框尺寸提前固定，加载前后布局不跳；离进入屏幕还有约 300px 时才开始加载。
```

## 03 滑到底加载更多（Infinite Scroll）
常见写法：做一个滑到底自动加载更多的列表 → 卡一下，一堆内容突然塞进来

```
做一个商品列表，滑到离底部还剩约一屏时就提前加载下一页；底部显示 3 个依次跳动的小圆点；新商品卡片每张错开 50ms，从下方 24px 处滑上来并淡入，约 0.45 秒，像传送带接上；加载期间滚动不卡、位置不跳；最后一页显示"没有更多了"。
```

## 04 AI 流式回复（Streaming Reply）
常见写法：做一个 AI 聊天，回复用打字机效果 → 干等几秒没反应，字一个个蹦，页面不跟着走

```
做一个 AI 聊天回复：发送后立刻出现回复气泡，里面 3 个小点呼吸跳动表示"正在思考"；开始回复后按词（中文 2–4 个字一段）一段段淡入，每段从透明、4px 模糊变清晰，末尾一个闪烁光标跟着走；气泡高度平滑长高，页面平滑跟随到底部；用户手动往上滑就停止跟随，滑回底部再恢复。
```

---

小提示：想要更像手机 App，可以在最后加一句"深色主题，按 390×844 手机尺寸，鼠标滚轮和手指滑动都能用"。

装了 skill 的话，直接说"用 ui-motion 给这个列表加载加上骨架屏"即可，AI 会按动效库里的完整参数实现。

## 05 启动页进首页（Splash → Home）
常见写法：打开时有启动页，然后进入首页 → 盯着 Logo 干等两秒，然后啪一下换成首页

```
做一个美食 App 的启动页，Logo 放大变成进首页的门，像拉开幕布：打开时深色背景中间是圆形 Logo，先轻轻呼吸缩放一次（约 600ms）；然后以 Logo 为圆心做圆形遮罩从中间放大到铺满屏幕（约 700ms，先慢后快），首页从圆里露出来；首页内容从下往上依次浮上来（每块间隔约 60ms，带淡入）；全程不出现白屏、不硬切；按 390×844 手机尺寸。
```

## 06 顶部进度条（Top Progress Bar）
常见写法：点开文章时要显示加载状态 → 原页面被盖掉，白屏转圈或一片灰块，好了整篇一下冒出来

```
做一个资讯 App 点开文章时的顶部进度条，像跑步冲刺：点文章后屏幕最顶上出现一条 3px 强调色细条，先快速冲到约 30%，然后越走越慢，最多停在 90% 等数据；数据回来时一下冲到 100% 再淡出；等待时原页面保留不动，不要整页白屏转圈；文章页加载好后标题、图片、正文从下往上依次淡入；用一个按钮模拟 2 秒的网络延迟；按 390×844 手机尺寸。
```

## 07 照片上传进度（Upload Progress）
常见写法：选 3 张照片上传，要显示上传进度 → 只给一排百分比，照片本身没变化，有的还弹窗挡住

```
做一个发帖页的照片上传进度，照片像被一点点刷亮：选好 3 张照片后立刻显示缩略图，每张先盖一层半透明深色蒙层；上传时蒙层从下往上退去，退到哪照片就亮到哪，缩略图中间有一个细圆环跟着转满；3 张错开开始（间隔约 300ms），各走各的进度；某张传完时圆环变成对勾弹一下再淡出；全部完成后"发布"按钮从灰色变成可点；上传时页面能继续打字，不要弹窗挡住；按 390×844 手机尺寸。
```

## 08 消息秒发（Optimistic Send）
常见写法：发送消息时要显示加载状态 → 先转圈，服务器回来消息才出现，这期间打不了下一句

```
做一个聊天页的消息秒发，像先上菜后结账：点发送后消息气泡立刻出现在对话里，从输入框位置滑上去并带一点回弹（约 250ms），不等服务器返回；输入框马上清空，可以接着打字；气泡旁先显示一个小时钟图标，发送成功后换成两个对勾；模拟网络延迟 1.2 秒；如果发送失败，气泡变浅红色并出现"点击重试"小红圈，不要弹窗；按 390×844 手机尺寸。
```

## 09 叫车等待（Ride Matching）
常见写法：点呼叫后显示正在等司机接单 → 一个圈加一句"正在呼叫"，地图不动，接单了文字一换

```
做一个打车 App 呼叫后等司机接单的页面，像水波一圈圈往外找人：地图上自己的定位点往外扩出一圈圈波纹（每圈约 1.6 秒，越扩越淡，3 圈错开）；周围几辆小车图标慢慢往你这边开；底部卡片显示"正在为你呼叫附近司机"和已等待的秒数在走；找到司机时波纹收回成一个点，其中一辆车沿路线开过来，底部卡片向上翻出司机信息（头像、车牌、几分钟到达）；用一个按钮模拟 4 秒后接单；按 390×844 手机尺寸。
```

## 10 加载失败重试（Error → Retry）
常见写法：做一个资讯 App 列表页，加载失败时可以重试 → 失败页还行，可重试完列表啪一下整页冒出来

```
做一个资讯 App 列表页的加载失败和重试，像断了的电话重新接上：加载失败时页面顶部导航和标签栏都保留，只在内容区原位显示一张简单的线条插画、一句"网络开小差了"和一个"点我重试"按钮，不要弹窗、不要整页白屏；点重试后按钮先缩成一个小转圈，内容区立刻换成和真实卡片一样形状的骨架屏；数据回来后卡片从上到下每张错开 60ms 依次浮现（淡入 + 上移 8px），骨架同步淡出；第一次加载默认失败，重试 1.2 秒后成功；按 390×844 手机尺寸。
```

## 11 新内容提示条（New Posts Pill）
常见写法：做一个社交 App 信息流，有新动态时提示用户 → 一条文字条，点了硬跳回顶部，新内容一下塞进来

```
做一个社交 App 信息流的新内容提示，像有人轻轻拍你肩膀：用户往下滑看旧内容时，有新动态到了也不打断他，页面不跳；顶部从上往下滑出一颗圆角胶囊"↑ 3 条新动态"，带 3 个小头像叠在一起，轻轻弹一下（约 300ms）；点胶囊后页面平滑滚回顶部（约 500ms），胶囊收回，3 条新动态从顶部一条条插进来（每条错开 80ms，高度从 0 展开 + 淡入），下面原来的内容平滑往下让位；用户自己滑回顶部时胶囊也自动收起；用一个按钮模拟新动态到达；按 390×844 手机尺寸。
```

## 12 搜索结果加载（Search Loading）
常见写法：做一个商城 App 的搜索页，显示搜索结果 → 要按搜索键，结果整块出来，搜不到就一句话

```
做一个商城 App 的搜索结果加载，像店员听你说完才去拿货：输入框里每打一个字不马上搜，停下约 300ms 才开始；开始搜时输入框右边出现一个小转圈，结果区先出 4 行和结果卡片形状一样的骨架；结果回来后一条条依次浮现（错开 50ms），标题里和搜索词一样的字用强调色加粗高亮；搜不到时显示一张简单插画、"没找到相关商品"和 3 个可点的推荐词胶囊，不要一片空白；清空输入框结果区平滑收起；模拟搜索延迟 600ms，输入"耳机"有结果，输入"xyz"没结果；按 390×844 手机尺寸。
```

## 13 断网提示（Offline Banner）

## 01 像素擦除 Pixel Wipe

```text
做一个手机 App 首次加载页：先用一张像素插画遮住整屏，加载完成时像素块逐块向右上滑走、露出下面的真实界面。画面 390×844。加载层切成 8 列 × 16 行、每格 48.75×52.75 的近似方形格子，拼成一张像素插画（暖橙太阳 + 三棵三角树 + 深棕地面），格子不是正方形也没关系，靠画面本身读出来。擦除时每格向右上斜移（横向 18–67px、纵向 -30 到 -65px）、同时缩小到 0.52、透明度归零，每格耗时 0.06 秒；出场顺序按“列号 + 行号×0.62”从小到大排，总跨 1.5 秒，先左上后右下，形成阶梯状推进。加载层中央有一个百分比（属于加载层，跟着一起擦掉），从 0 数到 100；但擦到三成时它开始整体变透明，到五成完全看不见——数字继续数，只是被擦掉了。底层界面是天气页：72° 大数字、五行小时预报、四个指标格、一张 AI 提示卡、底部 tab。底层卡片从 1.1 秒起就开始在加载层下面错峰上浮（擦开的格子里能看见它们在升起来），按温度块 → AI 卡 → 其余顺序，每张上浮 34–44px、0.42 秒。整体 3.0 秒内完成。
```

## 02 生成氛围 Generating Aura

## 六条的通用底线

1. **等待要给证据**：哪怕条不动，也要让用户看到"在读什么、做到哪一步、还剩多少"。
2. **完成要有交代**：填满弹一下、成卡撑开、文字换掉——让"结束"这件事被看见。
3. **两层不能叠影**：任何"旧页退出 + 新页进场"的组合，都要先退完后进场，或者用明确的遮罩隔开。
4. **背景换色要连状态栏一起换**：浅色页面用深色状态栏图标，这一条最容易忘。
5. **不用光晕、光雾、发光粒子**：加载动效靠形状和节奏取胜，不靠发光。
