# 按钮动效 · 9 个提示词

对应抖音视频：4个提示词，让AI做出有手感的按钮

不想装 skill？直接复制下面的提示词发给 AI 编程工具（Claude Code / Codex / Cursor 等）就能用。

每个都附了"常见写法"，对比一下就知道差在哪：只说"好看"，AI 多半只会给你换个颜色。

---

## 01 点赞爆粒子（Like Burst）
常见写法：做个好看的点赞按钮 → 爱心换个颜色，没有动画

```
做一个点赞按钮（Like Burst）：点击后爱心先缩小到 0.8 倍再弹到 1.2 倍，最后回到 1 倍，同时由灰色变成红色；爱心周围炸开 8 个彩色小圆点，向外飞散并淡出；右边的点赞数向上滚动 +1。总时长约 600ms，弹跳使用带回弹的曲线。
```

## 02 提交按钮三连变（Submit Morph）
常见写法：提交时加个加载状态 → 按钮旁边转个圈，成功没反馈

```
做一个提交按钮三段变化（Submit Morph）：点击后文字淡出，按钮宽度收缩成圆形，圆形中间出现旋转的加载圆环；1.2 秒后按钮变成绿色并画出对勾；再过 1 秒恢复原状。收缩约 300ms，使用 ease-in-out。
```

## 03 果冻开关（Jelly Toggle）
常见写法：做个开关 → 圆点平平滑过去，没有手感

```
做一个果冻开关（Jelly Toggle）：点击后圆点滑向另一端，滑动途中先横向拉长成胶囊形，到达终点回弹恢复圆形；底色从灰色渐变为绿色。时长约 350ms，使用带回弹的弹簧曲线。
```

## 04 长按确认（Hold to Confirm）
常见写法：删除前确认一下 → 弹出一个"确定删除吗？"

```
做一个长按确认按钮（Hold to Confirm）：圆形删除按钮，按住时外圈进度环顺时针走满，用时 1.5 秒；中途松手进度环倒退归零；走满后按钮左右轻震一下，变成对勾和"已删除"。适合删除等危险操作。
```

---

装了 skill 的话，直接说"用 ui-motion 做一个果冻开关"即可，AI 会按动效库里的完整参数实现。

# 第09期 · 5 个按钮动效（让 App 和小程序点下去有回应）

对应抖音视频：5种按钮动效，让App和小程序点下去有回应

## 05 磁吸按钮（Magnetic Button）
常见写法：鼠标放上去要有好看的悬停效果 → 碰到才上浮变色，不会被吸过去

```
做一个SaaS 官网首屏的"免费试用"按钮，鼠标靠近时按钮像被磁铁吸过去：鼠标进入按钮周围约 80px 范围时，按钮朝鼠标方向偏移（最多 14px），里面的文字再多偏一点（约 1.6 倍），有前后层次；偏移用平滑跟随（每帧追上剩余距离的 15%），不要一下跳过去；鼠标离开后按钮带一点回弹弹回原位；悬停时背景从鼠标进来的方向填满强调色；点击时按下缩到 0.96 倍再弹回；按 1440×900 电脑尺寸。
```

## 06 加购飞入（Add to Cart Fly）
常见写法：点击后要有加购反馈 → 只告诉你加好了，看不到东西飞进去

```
做一个商品详情页的"加入购物车"按钮，点一下商品图片飞进右上角购物车，像把东西扔进篮子：点击时按钮按下缩到 0.95 倍再回弹；从商品主图复制一个圆形小缩略图，沿抛物线飞向右上角购物车图标（先往上抛再落下，约 700ms），飞的途中慢慢缩小；落进去时购物车左右晃一下，红色角标弹出来并向上滚动 +1；按钮文字换成"已加入 ✓"，1.5 秒后恢复；按 390×844 手机尺寸。
```

## 07 播放暂停变形（Play ⇄ Pause Morph）
常见写法：点击播放按钮可以切换播放和暂停 → 图标啪一下直接换掉

```
做一个音乐播放器的播放按钮，点一下三角形平滑变成两竖条，像折纸翻过去：用 SVG 路径变形，三角形和两竖条的顶点一一对应，不是两个图标直接替换；变形约 320ms，带一点回弹，同时整个图标转 90 度；按钮按下缩到 0.92 倍再弹回；播放时专辑封面从 0.86 倍弹回原尺寸，暂停时缩回 0.86 倍；底部进度条跟着播放慢慢走；按 390×844 手机尺寸。
```

## 08 悬浮按钮展开（FAB Fan Menu）
常见写法：右下角加号按钮，点开显示几个选项 → 几个选项一下子全冒出来

```
做一个App 右下角的圆形加号按钮，点开后几个选项像打开折扇一样依次弹出：点击后加号旋转 45 度变成叉；3 个小圆按钮（拍照、写文字、录语音）从加号的位置向上依次弹出，每个晚 60ms，带回弹；旁边的文字标签稍晚一点从右往左淡入；背后页面变暗并轻微模糊；再点叉或空白处，选项按相反顺序收回；按 390×844 手机尺寸。
```

## 09 复制变勾（Copy → Copied）
常见写法：点击后提示复制成功 → 另外弹个提示框，按钮自己不变

```
做一个代码块右上角的"复制"按钮，点一下图标变成对勾，像盖了个章：点击后复制图标缩小淡出，对勾从 0.6 倍弹到原大，并且沿笔画一笔画出来；按钮文字从"复制"向上滚动换成"已复制"，颜色变绿；按钮宽度跟着文字平滑变宽，不要一下跳；不弹提示框；2 秒后自己换回复制图标；真的把代码写进剪贴板；按 1440×900 电脑尺寸。
```
