# 视频播放动效（第37期）

手机 App 视频页里 6 个跟手、有反馈的播放控件动效。每一条都能直接复制给 AI。

---

## 01 刷到自动播放（Auto Preview）

```
做一个手机 App 的「卡片滑到视野中央就自动播放」动效，手机屏 390×844，深色界面。页面是「为你推荐」信息流，顶部有标题和头像，中间一张大卡（宽 342、高 360、圆角 24），大卡下面是「接下来」三张竖版缩略（每张 106×150、圆角 14），再下面是两行带小图的小列表。
触发：用户向上轻推一下列表（手指从 y=660 上滑 120px，耗时 0.8 秒），大卡进入屏幕中央位置。
动作过程：卡片里的静态海报在 0.3–0.86 秒内淡出并轻微放大到 1.06 倍，同一位置的视频画面同时淡入（视频用照片缓慢推近 + 横向漂移的云带 + 沿对角线扫过的一道高光来表现「在播」）；卡片顶部的标签从灰底「预览」变成红底「正在播放」；底部出现一条细进度条，从 12% 缓慢走到 100%（5.2 秒一轮）；卡片投影加深、放大一点；卡片整体向上平移 56px，让位置更居中。
联动：下方三张缩略图和列表同时把亮度降到约 50%、饱和度降 40%、缩小 3%，把视线压回到主卡。
结束反馈：进度条走满后不跳变，静图重新淡入、视频淡出、周边内容回到原亮度，循环往复。
要求：所有变化都由时间驱动，可循环播放；不要用 CSS transition 或定时器；卡片里的文字和图片位置不能跳动。
```

## 02 点开变全屏（Card to Player）

```
做一个手机 App 里「点一下缩略卡，展开成全屏播放器」的动效，屏 390×844。界面是深色「媒体库」，两列共四张竖版卡片（每张 166×270、圆角 16、间距 16），下面是「继续观看」横向两行小卡。
触发：点击第二张卡片「城市夜行」的正中央。
动作过程：被点的卡片从它自己的位置和大小开始连续长大，0.30–1.28 秒内长到铺满整屏（宽从 166 到 390、高从 270 到 844、圆角从 16 到 0），位置从原位平滑过渡到左上角；卡片里的照片始终居中裁切、不换图、不跳帧。
分层出现：长到约 42% 时播放器界面开始淡入，70% 时中央播放键出现，62% 时顶部返回按钮和标题淡入，55% 时底部控制条淡入。播放器层包括：顶部渐变遮罩 + 返回圆钮 + 标题「城市夜行」+ 小字「EP.04 · 4K」；中央半透明播放键；底部渐变遮罩 + 进度条 + 左右时间码 + 上一首/播放/下一首三个按钮。
联动：其它卡片在被展开期间亮度降到 55%，被点的那张原卡隐藏在展开层之下不露出重影。
结束反馈：从顶部往下拖 90px（2.90–3.86 秒）原路收回，缩回原来的格子和尺寸，播放器层同时淡出，其它卡片亮度恢复。
要求：全程由时间驱动；图片在缩放中保持 cover 居中，不出现拉伸变形；不要用 CSS transition。
```

## 03 拖动进度（Scrub Tooltip）

```
做一个手机 App 里「拖动播放进度」的动效，屏 390×844。界面是浅色「最近观看」列表（四行白色圆角卡，左侧缩略图，右侧标题和「4K · 已看 12%」），屏幕底部悬浮一条深色胶囊迷你播放条（宽 362、高 62、圆角 31），里面有封面、标题「湖畔的清晨」、时间「0:00 / 0:06」、中间一段进度线（起点 x=150、长 150px）、右侧上下箭头和加号按钮。
触发：手指按住进度线上的播放头开始向右拖。
动作过程：三段拖动，分别从 10% 拖到 68%（0.84 秒）、再往前到 42% 的位置回拖（0.84 秒）、最后小幅回拖（0.80 秒）；拖动中用 ease-in-out，1:1 跟手，不做吸附延迟。
联动：播放头被按住时宽度从 8px 变成 12px、高度从 16px 变 24px；进度线填充色用强调色跟着走；播放头上方浮出一个强调色时间气泡（圆角 8、高 26、字号 11 等宽），实时显示「0:03 / 0:06」并跟着播放头水平移动；迷你播放条上方浮出一张 220×140 的预览帧卡片（圆角 14、2px 白描边、投影），左下角显示对应时间码、右下角写「预览」。
结束反馈：手指松开后气泡稍向下沉 8px 并缩到 0.86 倍淡出，预览帧同样下沉淡出；进度停在松手位置不回弹；重新按住立刻再次出现。
要求：气泡和预览帧不能用 CSS transition，全部按时间插值；列表不能被预览帧遮住；文字不能出框。
```

## 04 拖动时聚焦（Focus Scrub）

```
做一个手机 App 里「一按住进度条，整个界面就退到后面、只留下波形」的动效，屏 390×844，深色播客页。
静止态：顶部小字「深夜电台 · EP.12」和返回箭头；中间 300×300 圆角 18 的封面照片；下面「Midnight Drive」标题和副标题；再下面是「0:46 / 2:34」时间；下方一条 310×48 的波形（44 根圆角竖条，高度在 8–38px 之间随机但固定）；最下面是上一首/播放/下一首和一行互动数据。
触发：手指按在波形上。
动作过程（0.50–1.30 秒）：封面、标题、副标题、按钮、底部数据在 0.22 秒内一起变暗后退——封面缩到 0.62 倍、下移 40px、亮度降到 42%、透明度降到 50%；一层 rgba(4,5,8,.72) 的遮罩淡入到 82%；波形同时从屏幕下部（y=560）平滑移到中部（y=388），高度从 48px 长到 132px，宽度从 310 长到 330，清晰可见地放大。
联动：波形里已播放部分的竖条变成强调色（从左往右推进），未播放保持半透明白；时间文字随拖动从 12px 放大到 54px、变粗、左对齐移到波形左上方，并实时更新成分:秒（如「0:58」）。
结束反馈：松手后（2.10–2.52 秒）所有元素在 0.42 秒内原路回到静止态——波形缩回原尺寸原位置、时间文字缩回小字、遮罩淡出、封面和标题回到 100% 亮度和原缩放；整个过程不能跳变、不能闪黑。
要求：按时间插值，不用 CSS transition；放大的波形要真的看清每根竖条，不能糊成一块。
```

## 05 横滑调倍速（Speed Slide）

```
做一个手机 App 里「横滑调倍速」的动效，屏 390×844，全屏竖屏视频页。
画面：一张照片铺满全屏作为视频画面（用缓慢推近和轻微位移表现正在播放），顶部有半透明的返回圆钮和标题「城市夜行 · 4K」，中央一个 70px 的圆形播放键，底部有细进度条和左右时间码。
触发：手指在画面中间横向滑动。
动作过程（0.60–2.30 秒）：顶部滑出一条深色读数条（高 112、从 y=44 开始，带上下渐变），中间显示当前倍率，等宽大字号 46px；倍率随滑动距离实时变化：从 1.0× 先升到 2.6×（前半程），后半程回落到 1.8×，用 ease-in-out 插值。
联动：视频画面随倍率做轻微横向位移（每 1 倍速度偏移 22px，最大约 35px）和上下偏移，同时放大 1.06 倍并做极轻微呼吸缩放；播放键、顶部标题、底部控制条在滑动时淡到约 12% 的透明度让位给读数条。
结束反馈：松手后（2.30 秒）读数条在 0.3 秒内淡出并上移 18px，倍率回到 1.0×，画面回到原位，所有控制件恢复不透明；不出现任何跳帧或闪烁。
要求：全部时间驱动，不用 CSS transition；读数必须逐帧跟着手指变化，不能只在端点跳两下；数字用等宽字体、直播中不抖动宽度。
```

## 06 下滑收成迷你条（Mini Dock）

```
做一个手机 App 里「下滑把播放页收成底部迷你条」的动效，屏 390×844。
背景层：深色「我的收藏」列表，六行圆角卡片，每行左侧缩略图、右侧标题和时长。
前景层：一个全屏播放页（390×844，深紫色渐变），顶部一条小横条（胶囊把手）、中间「正在播放」小字、300×300 圆角 20 的封面、标题「深夜剧场 · 第 12 集」、副标题、进度条与「21:04」「−36:12」、三个播放按钮、一行「队列 / 分享 / 收藏」。
触发：在全屏页上向下拖动。
动作过程（0.60–1.46 秒）：全屏页跟着手指下沉 190px、缩到 0.84 倍、圆角从 0 长到 26，同时背景列表的遮罩从 62% 降到 12%，列表略微放大（0.94→1）。
联动：收起的最后 45% 阶段，屏幕底部（距底 20px、宽 342、高 62、圆角 17）浮出迷你条：封面 46×46、标题「深夜剧场 · 第 12 集」、一段细进度条、右侧播放和下一集按钮；迷你条从下往上 40px 弹入、缩放 0.94→1。同时全屏页在 62%–100% 之间透明度降到 0 完全退场，不留下重影。
结束反馈：向上拖动（3.10–3.86 秒）时反向播放：迷你条缩小下移淡出，全屏页从 0.84 倍回到 1.0、位置回到 0、圆角回到 0、透明度回到 1，遮罩重新加深，列表恢复原位。
要求：全程按时间插值，不用 CSS transition；迷你条和全屏页不能同时占着同一个位置露出两层内容；进度条播放时持续走。
```
