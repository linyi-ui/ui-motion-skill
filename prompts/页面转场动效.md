# 页面转场动效 · 6 个提示词

对应抖音视频：6个页面转场让App换页像丝滑切片

不想装 skill？直接复制下面的提示词发给 AI 编程工具（Claude Code / Codex / Cursor 等）就能用。

每个都附了"常见写法"，对比一下就知道差在哪：只说"换个页面"，AI 多半给你一个淡入淡出。

---

## 01 卡片变整页（Card Morph）
常见写法：点卡片 → 新页面直接出现，或者整卡放大再淡出

```
做一个手机钱包 App 的卡片展开转场：浅灰底，顶部 Wallet 标题和头像，下面是 2×3 圆角卡片网格（每张 174×104、圆角 18，颜色不同，卡上有名称和金额）。点最后一张青绿卡右侧的「•••」：这张卡在 0.72 秒内从左下格原位放大成整页头部（高度 104→296、圆角 18→0、宽度 174→390），动画用先快后慢的 ease-out；卡片里的小字同步换成大页头部（「Team Wallet」、$9,860、卡号），接着下面 6 行设置项（Connections / Backup / Approvals / Notifications / Tools / Options）以每行 0.06 秒错峰、向上 24px 淡入，底部浮出一条圆角按钮条。点右上关闭：整页头部 0.68 秒缩回左下格原位，网格其余卡片同时淡回。要求：放大过程中卡片内边距和字体一起过渡，不能只做整卡 scale；关闭时反向播放同一段缓动，不跳帧。
```

## 02 弹层长成整页（Sheet to Screen）
常见写法：弹层里点一项 → 弹层关掉，新页面从右边推进来

```
做一个手机钱包 App 的底部弹层长成整页：浅灰底，2×2 卡片网格，底部先滑上来 390×300 白色圆角弹层（顶部有把手、标题 New Wallet、两行选项 Add Existing / Create New）。点 Add Existing：弹层在 0.67 秒内从 300 长到 844 高（顶边从 y=544 升到 0、圆角 28→0），用 ease-in-out；长到一半时内容交叉——第一层两行选项 0.25 秒淡出，第二层「Choose Wallet Group」标题、三行分组和虚线的 New Group 行依次从下 22px 上浮淡入（每行错峰 0.08 秒），底部导航栏随弹层一起升上来；最后 Continue 按钮淡入，点它时缩到 0.94 再回弹。点右上关闭：整页在 0.65 秒内缩回 300 高的弹层再滑走，内容始终停在第二层，不许在收起时闪回第一层。
```

## 03 返回视差（Back Parallax）
常见写法：点返回 → 整页向左推送，两层一起动

```
做一个手机商店 App 的返回视差转场：先显示深色商品列表页（顶部返回箭头、Shop all 标题、分类胶囊、两张橙色商品卡、底部黑色浮动导航栏）。点返回箭头：当前页在 0.8 秒内整体右滑 390px 移出屏幕（ease-in-out），它左边缘带一层 46px 宽、34% 黑色的投影，压在下层上；底层白色「All products」页同时从 -78px 回到 0，速度约是上层的五分之一，形成前后差速。上层的分类胶囊和商品卡在滑动中还额外多滑 12px，制造轻微视差。返回完成后底层页面的搜索框、分类胶囊和 2×2 商品网格是完整可读的。要求：两层必须有明确前后层级和阴影，不能两层同速一起滑。
```

## 04 网格塌缩（Grid to Tabs）
常见写法：往上滑 → 大图标网格直接消失，顶部标签栏淡入

```
做一个手机城市探索 App 的滚动塌缩导航：深色底，顶部品牌行和搜索框，主图区（MONUMENTS 标题 + 建筑插画），下面 3×2 大图标网格（每格 100×98，彩色圆角方块 56px + 文字标签），再下面是「Explore India's heritage」。向上滚动 0.8 秒：六个彩色图标沿弧线各自飞向顶部，同时缩小到 20px、圆角 16→6，排成一行落在 y=114 的标签栏位置；图标下面的文字标签先淡出，标签栏的 6 个新文字标签在图标落位后淡入，第一个下面出现强调色下划线；主图和搜索框向上滑出淡出，下方列表四条卡片错峰升起。要求：图标是逐个飞进去的（每个错开 0.035 秒），不是整块网格直接缩小；标签栏吸顶后位置固定不动。
```

## 05 图标飞行（Icon Flight）
常见写法：点新增 → 旧页关闭，新页出现一个同样的图标

```
做一个手机钱包 App 的共享元素转场：先在「Choose Wallet Group」页（白色底、三行分组、底部一个虚线 New Group 行）。点 New Group：行内的青绿色加号图标在 0.7 秒内沿一条略微上凸的路径飞到页面顶部中央，途中先放大到 1.35 倍再收回到 1 倍，落位后成为新页标题上方的图标；同时旧页整体缩到 0.97 并淡出，新页「Name Your Wallet」从 0.97 放大淡入。新页里的标题、输入框、建议列表按 0.07 秒错峰从下 14px 上浮，输入框里自动逐字打出「Team Wallet」并显示青色光标闪烁，五条建议行依次出现，最后 Create wallet 按钮淡入。要求：加号是同一个元素连续飞行，不允许旧页消失、新页凭空出现一个图标。
```

## 06 导航长成面板（Bar to Panel）
常见写法：点"更多" → 从底部滑上来一个全新的菜单弹窗

```
做一个手机理财 App 的底部导航展开面板：米金色底，上方金条插画、Earn 1% extra gold everyday、三张日/月/一次性档位卡和黑色按钮；底部是一条黑色导航栏（左侧 CRED MONEY 小字、右侧下箭头、下面 5 个 tab 图标）。点右侧下箭头：导航栏在 0.7 秒内从 80px 高长到 544px（顶边从 y=764 升到 y=300、圆角 22→26），用 ease-in-out；箭头同时旋转 180 度；长高过程中 CRED MONEY 小字淡出，面板里 4 行选项（Statements / Settings / Help & Support / Log out）以每行 0.07 秒错峰从下 16px 上浮；背景页面同步压暗 28%。展开后 5 个 tab 图标仍停在面板最底部同一位置，不能跟着长高一起被推走。点箭头收起：反向播放同一段动画。
```
