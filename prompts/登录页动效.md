# 登录页动效 · 4 个提示词

对应抖音视频：第19期 4个登录页动效

不想装 skill？直接复制下面的提示词发给 AI 编程工具（Claude Code / Codex / Cursor 等）就能用。

每个都附了"常见写法"，对比一下就知道差在哪：只说"做个登录弹窗/登录页/密码框/倒计时按钮"，AI 多半做成从中间冒出来、一切换就闪、一下全露出来、数字干巴巴地变。

---

## 01 登录弹窗（Login Modal）
常见写法：做一个点收藏时弹出的登录弹窗 → 弹窗从屏幕中间直接冒出来，背景一动不动，只能点 × 关，拖不动

```
做一个游客点「收藏」时弹出的登录弹窗：弹窗从被点的收藏按钮位置放大出来（从 0.3 倍长到 1 倍，带一点回弹，约 380ms），同时背后的页面缩小到 0.94、变暗并模糊；弹窗里有「本机号码一键登录」按钮和其他登录方式；手指按住弹窗往下拖时弹窗跟手下移，背景跟着慢慢变亮，拖过一段距离松手就缩回收藏按钮关闭，没拖够就弹回原位。
```

## 02 登录方式切换（Method Switch）
常见写法：做一个验证码登录和密码登录可以切换的登录页 → 一切换整块"啪"地闪一下换掉，表单高度直接跳，手机号还被清空

```
做一个登录表单的「验证码登录 / 密码登录」切换：顶部两个标签，下面的滑块跟着平滑移到选中的标签；切换时旧输入框向一侧淡出、新输入框从另一侧滑入，整个表单卡片的高度平滑伸缩到新内容的高度（约 300ms），下面的登录按钮跟着平滑移动、不跳动；已经输入的手机号保留不清空。
```

## 03 密码小眼睛（Password Peek）
常见写法：做一个能显示和隐藏密码的输入框 → 点一下眼睛，密码一下子全露出来，眼睛图标直接换一张

```
做一个密码输入框的显示/隐藏小眼睛：点眼睛图标时，眼睛像真的眨一下（上眼皮合上再睁开，约 250ms），密码圆点从左到右一个接一个翻转成明文字符，每个间隔约 40ms；再点一次眼睛闭上，文字依次翻回圆点；切换时输入框宽度和光标位置不变、不跳动。
```

## 04 验证码倒计时（Resend Timer）
常见写法：做一个获取验证码的倒计时按钮 → 数字干巴巴地一秒换一个，数完按钮直接变回去，没有任何反应

```
做一个「获取验证码」按钮：点击后按钮按下缩小再弹回，文字变成「60s 后重发」，按钮变灰不可点；秒数每过一秒像翻牌钟一样旧数字向上滑出、新数字从下方滑入；倒计时结束时按钮恢复强调色并轻轻弹一下，文字变回「重新获取」。
```
