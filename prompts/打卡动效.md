# 打卡动效 · 4 个提示词

对应抖音视频：4个打卡动效，让用户天天想打开

不想装 skill？直接复制下面的提示词发给 AI 编程工具（Claude Code / Codex / Cursor 等）就能用。

每个都附了"常见写法"，对比一下就知道差在哪：只说"点一下打个卡"，AI 多半只会把按钮换成勾。

---

## 01 长按打卡（Hold to Check-in）
常见写法：点一下打个卡 → 按钮直接变成勾，没有按住、没有填充过程

```
做一个手机打卡页：按住中央圆按钮，按钮轻微内陷，进度环从 12 点顺时针填满；填满瞬间白色扇叶炸开，收成金属圆盘，黑色对勾描边画出；底部日历今天打勾，连续天数从 6 变 7。
```

## 02 能量飞入（Energy Fly）
常见写法：完成任务加个奖励 → 右上角数字直接 +1，看不到奖励从哪来

```
做一个手机学习完成页：任务完成后，屏幕中央弹出粉色 +1 能量胶囊，带过冲回弹；停一下后胶囊缩小，沿弧线飞向右上角计数器，落地消失，数字从 18 变 19 并弹一下，能量条同步加一格。
```

## 03 里程碑揭晓（Streak Reveal）
常见写法：连续天数到了换个颜色 → 卡片原地变色，没有弹起、没有奖励

```
做一个连续打卡里程碑页：灰色 10 天卡片从下往上弹起并变橙；上方弹出 +15 能量，右上宝石数字从 120 增到 135 并弹一下；进度条从 9/10 延到 10/10，卡片左滑把 14 天带到中间；底部按钮滑入。
```

## 04 目标选择页（Goal Commit）
常见写法：做个目标选择 → 新页面直接出现，选项没有入场，像一张静态表单

```
做一个目标选择页：点按钮后第二页从右滑入、第一页左移；7/14/30/90 四个选项依次从下方弹上来，间隔 0.13 秒；点 7 天后它填青色、文字变深、右侧出现对勾；底部按钮最后滑入。
```

---

装了 skill 的话，直接说"用 ui-motion 做一个长按打卡"即可，AI 会按动效库里的完整参数实现。
