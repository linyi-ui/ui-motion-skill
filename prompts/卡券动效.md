# 卡券动效 · 6 个提示词

对应抖音视频：6个卡券动效，出票开卡都像真的

不想装 skill？直接复制下面的提示词发给 AI 编程工具（Claude Code / Codex / Cursor 等）就能用。

每个都附了"常见写法"，对比一下就知道差在哪：只说"做个卡券页面"，AI 多半只会把卡片硬切出来。

---

## 01 票档横滑（Plan Tab）

常见写法：点一下标签就换内容 → 整页硬切，标签胶囊瞬移，卡片和背景都不动

```
做一个票档切换页：顶部三个标签「看台 / 内场 / VIP」，点标签或左右滑动时，当前标签的胶囊向两边拉长，标签从灰变白；整页内容向左滑出 390 像素，新档位从右边滑入，用时 0.28 秒、先快后慢，末尾回稳 4 像素；背景色同时交叉淡入，从冷蓝过渡到墨绿再到暖铜，用时 0.35 秒；顶部卡片图延迟 0.55 秒再淡入，用时 0.65 秒；底部「加入」按钮固定在屏幕底部，只换文字，不跟着页面移动。
```

## 02 滑动选票（Ticket Slider）

常见写法：拖滑块只改数字 → 数字瞬间跳、没有金票粒子、按钮总价不同步

```
做一个选票数量的金色滑块：拖动滑块时，上方张数跟着滑块位置线性变化，从 30 张拖到 218 张再拖回 0，数字直接跳变、不做滚动；每过一段，就从滑块左上角喷出 3 张小金票，水平向左上方飞、边飞边旋转并淡出，寿命约 0.6 秒；轨道已填充段用深灰、未填充段用浅灰；下方按钮总价实时按张数乘 5000 更新；拖回 0 张时按钮立刻变灰，并出现一个转圈加载指示。
```

## 03 票券打印（Ticket Print）

常见写法：点出票按钮 → 票直接出现，没有压窄、没有底部上色、没有倒计时

```
做一个出票页：页面先在「正在出票…」状态，1.05 秒时一帧硬切成左右两个按钮「再买几张 / 我的票券」；2.2 秒时底部六张票条同时压窄到 0.18 倍，中心线不动，最窄时蓝紫色从票面底部向上灌满，再回到原宽；2.86 秒倒计时「06:17:58」淡入，之后每秒减一；底部社交文案交叉淡出淡入，不滑动；两个按钮位置全程不动。
```

## 04 会员卡就绪（Card Ready）

常见写法：光面直接变成卡 → 没有特写硬切、没有指数收缩、没有黑卡堆背景

```
做一个会员卡就绪页：前 1.78 秒是整屏卡片特写，粉色渐变卡面占满屏幕，标题和按钮压暗；1.78 秒一帧硬切到全景，黑色卡堆出现在背景里；卡片从 291 像素宽指数收缩到 162 像素，同时中心从 x=166 右移到 x=217、倾角从 -25 度转到 -20 度，用时约 5.7 秒、越收越慢；标题、副文和白色「继续」按钮在切后 0.2 秒内落位，之后完全静止。
```

## 05 会员卡装配（Card Setup）

常见写法：卡片直接出现 → 没有加载页、没有交叉淡入、没有整体上移

```
做一个开卡页：先是加载页，标题「正在设置账户」、下面一块深色卡片占位和一个小转圈；0.7 秒内新旧两页交叉淡入，新页整体向上移约 20 像素；新页左上角一个 44 像素的关闭按钮，中间是 342×240 的深色卡面，卡面左上角转圈、右上角是用户名胶囊；下方依次是「你的卡已就绪」、两行说明、两列权益网格、底部白色「立即验证」按钮；过渡期间元素不横向移动，落位 1 秒后按钮变灰并出现转圈。
```

## 06 收进卡包（Wallet Slip）

常见写法：卡直接消失 → 没有固定媒体框、没有三段硬切、没有金属卡入皮套

```
做一个卡包入口的媒体框动效：固定一块 348×210 的媒体框，内容用硬切切换——0.42 秒先切成碳纤维卡特写，卡片缓慢转 15 到 25 度；2.62 秒整块切成浅色文字卡「你已解锁会员卡包」；3.92 秒再切成金属卡加半透明皮套，卡片先下沉 30 像素，再用 1.1 秒上滑 30 像素进入皮套，皮套前片不透明度 0.88、遮住卡片下半部；页面其他内容一帧不动，媒体框始终不缩放、不溢出。
```
