# 相机交互动效（第31期 · 6 个）

一次拍照的六个瞬间：对焦 → 录像 → 调参 → 展开控制 → 换构图 → 变焦。
全部为手机端相机 / 拍照类 App 的常用交互，每个都配完整提示词。

---

## 01 对焦方框 Focus Bracket

**场景**：拍照 / 扫码 / 识别的取景器，点一下告诉用户"我在这里对上了"。

**提示词**

```
做一个相机取景器的点击对焦动效，深色相机界面，取景画面是一张真实海边照片。点一下取景器任意位置后：在点按处立刻出现一组四角括号对焦框（不要整圈方框，四个 L 形角，每个角的两条臂各长 34px（对焦框整体约 140×140px）、线宽 2.5px，强调色），0–0.20 秒从 1.55 倍缩到 1 倍，同时整体旋转 -58° 到 0°（像拧了一下镜头），弹性缓动 cubic-bezier(.34,1.56,.64,1)；对焦框中间先弹出一条 26px 的细十字，0.14 秒内长出来；0.55 秒后四角向外轻推 6px 并停住，中间闪一下强调色柔光（最多 0.4 秒淡掉）；1.35–1.62 秒做一次「合焦」：整体放大到 1.06 倍再回 1（正弦 0→1→0），1.4 秒起画面四边出现 4 条水平对齐刻度线；2.42–2.7 秒对焦框整体淡出。整个过程 2.7 秒，只播放一次，不要循环。
```

**要点**
- 四个 L 形角，不要整圈方框。
- 弹出同时整体转一下，像拧镜头。
- 停住后轻微合焦一次再淡出。

**注意**：亮照片上用白框 + 深色投影，强调色框会看不见。

## 02 快门拖拽锁定 Shutter Drag Lock

**场景**：相机录像模式，从拍照切到录像。

**提示词**

```
做一个相机录像快门的拖拽锁定动效，深色取景器界面。底部一条横向轨道，左端是直径 80px 的白色圆环 + 内圈红色圆形快门（红色直径 54px），轨道右端是一个 56px 的白色细圆环锁定图标。手指按住红色快门往右拖 1.2 秒（位移约 110px）：快门被横向拉长，外圈宽度从 80px 长到 136px，内红圆跟着横向鼓包（宽度 54→76px），像拉橡皮筋；拖到 62% 位置时越过阈值（约 0.62 进度），快门「啪」一下收成 54×54 的方形录制键（圆角从 27px 收到 6px，用 spring 曲线先过冲到 1.04 再回落），右侧锁定圈淡出，右边从 0.7 倍弹出一个 56px 白色圆形拍照键；同时顶部中央淡入一个红点 + 「00:00」计时（红点闪烁）。3.5 秒点方块停止，3.55–3.97 秒整条完整还原成原来的红色圆快门。
```

**要点**
- 拉长 + 鼓包，像橡皮筋。
- 过阈值瞬间收方角，要有过冲。
- 必须做反向还原动画。

## 03 刻度旋钮横滑 Dial Scrub

**场景**：相机参数（快门速度 / 曝光）、音量、滤镜强度。

**提示词**

```
做一个相机顶部刻度旋钮的横滑动效，深色相机界面。顶部是一个 342×78px 的紫色圆角旋钮（渐变 #7B5CFF → #5B3AD6），里面是横向重复的细刻度线（间距 18px，每 5 条加长），中间一条 3px 强调色竖指针固定在正中不动，旋钮中间显示当前读数（1/60、1/80、1/125…到 1/2000）。手指在旋钮上横滑 1.85 秒（位移 130px）：刻度整体横向滚动并循环，读数按滚动量跳档，滚动时旋钮整体轻微倾斜 ±2.5°，读数有 1px 的纵向抖动（模拟摩擦感）。松手后 0.42 秒内吸附：滚动位移弹回最近的整格（36px 的整数倍，正好等于两条刻度线的间距 18px × 2，保证指针落在刻度线上），旋钮回正，读数停稳不再抖。整个过程只播一次，吸附必须有可见的回弹，不能直接硬切到位。
```

**要点**
- 刻度和读数一起动。
- 中间指针固定不动。
- 松手吸附要有回弹。

## 04 控制盘错峰展开 Controls Stagger

**场景**：相机高级模式、剪辑工具栏这类"点一下展开一排控件"。

**提示词**

```
做一个相机控制盘错峰展开动效，深色取景器界面。底部左下是一个相册缩略图，中间是白色圆形快门，右下是一个 46px 的圆形箭头按钮。点箭头后：一排 4 个竖向刻度盘（Zoom / Exposure / Warmth / Focus，每个 74×150px）从左到右依次从下方 46px 处滑上来并淡入，每个相隔 0.09 秒，用 spring 缓动（先到 1.04 倍再回 1）；箭头自身翻转 180°。再点第二个 Exposure 盘：它上方 0.34 秒长出一块 74×108px 的点阵网格（5 列 × 6 行小圆点），网格从 0.7 倍往上弹到 1 倍；网格里一个高亮点沿「横=快门速度、纵=ISO」方向移动（0.75 秒），同时 Exposure 读数从 -0.3 滚到 +0.7。再点箭头收起：4 个盘按相反顺序向下滑出淡出。
```

**要点**
- 错峰 0.09 秒，这是"琴键感"的来源。
- 弹起带 1.04 倍过冲。
- 二级操作从被点的控件位置长出来。

## 05 取景框形变 Mask Morph

**场景**：拍照取景遮罩、头像框、贴纸边框。

**提示词**

```
做一个相机取景框形状形变动效，深色相机界面，取景画面是真实海边照片，取景框是画面中间 200×240px 的遮罩（框外压暗）。点一下取景框：遮罩形状用 clip-path 在花形、心形、椭圆、四叶草、圆角方形之间切换，每次切换 0.22 秒，切换时整体弹一下（先到 1.06 倍再回 1），边框内侧一圈强调色细线闪一下；连续点 5 次依次变 5 个形状，形状名在下方显示。随后两指张开把遮罩放大 1.22 倍（0.9 秒）；再拖动遮罩移动 38px，拖动时出现一条横线和一条竖线作为对齐参考，松手 0.25 秒内自动吸附回中心；最后底部升出一条背景色板（5 个色圆）淡入。形状要真的变轮廓，不能只改圆角。
```

**要点**
- 必须真的换轮廓（clip-path / path）。
- 每次切换小回弹 + 边框闪一下。
- 拖动给对齐线，松手吸附。

## 06 弧形变焦条 Zoom Arc

**场景**：相机变焦档位、沿弧线排布的档位选择器。

**提示词**

```
做一个相机弧形变焦条动效，深色取景器界面，快门在底部正中。快门上方有一条很细的半透明圆弧（圆心在屏幕下方外部，半径 196px，从左侧 -128° 到右侧 -52°），弧上均匀排 4 个档位：.5x、1x、2x、5x（38px 的圆形文字按钮）。一个 40px 的白色圆形胶囊指示器吸附在弧上，胶囊盖在选中档位下面一层，档位文字在胶囊上层显示，初始停 1x。点 2x：胶囊沿着弧线滑到 2x 的位置（0.42 秒，spring 缓动，允许过冲 4% 再回），滑动时顶部中央显示大字读数并跟着档位切换；点 .5x 再滑到最左；手指拖到 5x 时胶囊跟手沿弧走，松手吸附到最近的档位；最后点 1x 回到中间。选中的档位文字变成深色、字号放大 1.06 倍，未选中的保持白色半透明。胶囊必须贴着弧走，不能走直线。
```

**要点**
- 指示器贴着弧插值，不能走直线。
- 选中档位变深色 + 放大 1.06。
- 允许 4% 过冲。
