# 聊天动效 · 4 个提示词

对应抖音视频：4个聊天动效，让对话有来有回

不想装 skill？直接复制下面的提示词发给 AI 编程工具（Claude Code / Codex / Cursor 等）就能用。

每个都附了"常见写法"，对比一下就知道差在哪：只说"加个动画"，AI 多半只会让元素原地蹦一下。

---

## 01 输入框收起变形（Composer Collapse）
常见写法：键盘收起时输入框变成底部一颗胶囊 → 输入框突然消失、再冒出一颗新的，键盘瞬间没

```
做一个聊天输入框：键盘收起时，输入框一边向下移动一边变矮变圆，工具按钮收进两侧，最后变成底部一颗浮动胶囊（加号、按住说话、键盘图标）；点胶囊里的键盘图标，再沿同一条路径展开回完整输入框，键盘同步滑出。
```

## 02 气泡边打边长（Live Bubble）
常见写法：打字的时候气泡会随着文字变长 → 固定宽度的框，字多了挤成两行小字或直接截断

```
做一个聊天气泡：用户每打一个字，右侧草稿气泡的宽和高都实时跟着变，换行时弹性变高再回弹，退格时缩回去；字变多时字号自动缩小，始终不溢出、不截断。
```

## 03 正在输入提示条（Typing Pill）
常见写法：对方正在输入的时候显示提示 → 只在标题下面加一行小字，标题纹丝不动

```
做一个聊天列表标题栏：好友开始输入时，一条胶囊提示从右侧滑进来，把左边的标题往左挤出屏幕，胶囊里三个点依次跳动；停止输入后，胶囊滑回右侧，标题带着轻微回弹滑回原位。
```

## 04 双击爱心回应（Heart Burst）
常见写法：双击消息会出现爱心 → 爱心原地放大一下就消失，头像没反应，也没有回应计数

```
做一个双击消息回应：双击消息气泡，三颗爱心从手指位置弹出，先交错散开，再沿弧线一起飞向右上角的头像，越靠近越大，最后缩小被头像吸进去，头像缩一下再弹回，消息下方出现一颗爱心回应。
```
