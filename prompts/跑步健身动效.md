# 跑步健身动效（第32期 · 6 个）

一次晨跑的六个瞬间：设目标 → 开跑倒计时 → 跑步中心率 → 调下个目标 → 看年度进度 → 年底回顾。
全部为手机端健身 / 跑步类 App 的常用交互，每个都配完整提示词。

---

## 01 频率步进 Stepper Ticker

**场景**：设置每周跑步次数、每日目标、训练频率这类"加一减一"的数值。

**提示词**

```
做一个跑步 App 的「每周跑步次数」选择动效，深色界面。页面顶部两行标题「How often would you like to run?」+ 灰色小字说明；中间一张 342×232px 的深灰圆角卡片，卡片中央是超大数字（102px，粗体白字），下方一行小字「times per week」，卡片左右两端各有一个 56px 圆形按钮「−」和「+」；卡片下方一行小字「Which days work best?」，再下面一排 7 个 36px 圆形星期胶囊（M T W T F S S）；最底部一条 342×54px 的黄色圆角「Continue」按钮。点「+」时：新数字从下方 112px（整个数字高度）的偏移处滑入，同时从 11px 模糊变清晰、透明度从 0.15 升到 1，用 0.34 秒 cubic-bezier(.42,0,.58,1) 做纵向滚动；旧数字同时向相反方向滑出、变模糊、淡出，形成竖向滚轮的换位感。点「−」时方向相反（新数字从上方滑入），必须和「+」的滚动方向完全镜像。数字每变一次，下方 7 个星期胶囊的前 N 个（N＝当前次数）同时从半透明灰底灰字「点亮」成白色实心 + 深色字，用 0.3 秒过冲弹性曲线（1→1.04→1）；减少次数时，多出来的胶囊反向变回灰色。整个演示：2→3→4→5→4（最后一步用「−」展示可逆），每次间隔约 0.4 秒，只播一次不循环。
```

**要点**
- 位移量必须等于数字框的整数高度（112px），否则滚动时会露出上一行。
- 换位的"糊"来自同时做位移 + 模糊 + 透明度三件事，只做位移会显得生硬。
- 加减两个方向必须镜像，加号往上滚、减号就得往下滚。

**注意**：附带的联动元素（星期胶囊、档位格子）要写在同一个数字变化事件里，否则会出现"数字变了但胶囊没跟上"。

## 02 开跑倒计时 Countdown Ring

**场景**：开始训练 / 开始计时前的 3-2-1 准备页。

**提示词**

```
做一个健身 App 的「开跑倒计时」动效，蓝色渐变背景（#39B4F5 → #1E7CE0）。顶部居中一行小字「1 of 12」，下面一行白色标题「Jumping Jacks」；中间一个 324px 的白色实心大圆，圆里是一个简笔人形（蓝色圆头 + 蓝色躯干 + 蓝色手臂 + 橙色双腿），做开合跳循环动作（每秒一次：站立 ↔ 双手举过头顶、双腿张开）；白色大圆外沿套一条 9px 的浅蓝色进度弧。大圆下方是一个 96px 的倒计时徽章，里面有白色数字和一条细白环，再下面一行小字「Get ready」。倒计时从 3 开始，每秒减 1：数字在每次换位时先缩小到 0.55 倍、模糊 8px、淡出，新数字立刻从 0.55 倍放大回 1 倍并清晰（0.34 秒 spring 缓动），形成「旧数字缩掉、新数字弹进」的换位感；同时大圆外的浅蓝进度弧和徽章里的细白环都从满圈逆时针递减到 0，每一秒走完一整圈。3→2→1 各 1 秒，1 结束后整块切换成正式训练计时：白色大字「30」+ 下方小字「seconds」，徽章和细环淡出。整个过程约 3.6 秒，只播一次。
```

**要点**
- 数字换位是"缩放 + 模糊 + 透明度"三合一，单纯换文字没有节奏感。
- 外圈进度弧每秒走满一整圈，方向是逆时针递减。
- 结束要有一个明确的"换阶段"动作（切到正式计时），不能停在 1。

**注意**：`stroke-dasharray` 做递减时要用周长做上限常量，别用百分比，否则不同半径的环速度不一样。

## 03 心率波形 ECG Trace

**场景**：运动数据页、健康监测页、任何需要"正在实时采集"感觉的图表。

**提示词**

```
做一个健身 App 的「心率波形」实时描线动效，深红黑底（#120609）。顶部左边白色标题「Lab」，右边两个白色小图标（铃铛、头像）。中间一块 390×250px 的波形区，铺一层很淡的红色网格（39px 一格，透明度 0.055）。波形是一条心电曲线：基线在中间偏下，每个心动周期 130px 宽，形状依次是 P 波小鼓包（峰值 +0.14）、QRS 尖峰（先下探 -0.16，再冲到 +1.0，再回落到 -0.34）、T 波圆鼓包（峰值 +0.19），其余段落贴基线；整条曲线必须严格以 130px 为周期重复，保证扫描重置时看不出接缝。整条波形先以 0.15 透明度的暗线完整显示，然后用 128px/秒的速度从左向右「描线」：已描过的段落变成亮红色（#FF5A6E，2.8px 宽，外面套一层 7px 的半透明红色柔光，中间再叠一条 1.1px 的浅粉高光），描线前端有一个 20px 的柔光圆点光标 + 3.6px 白色实心圆点，还有一条贯穿波形区的暗红竖线跟着走。描到 390px 右边界后立刻从最左边重新开始。下方配有静止的指标区：AVG. HEART RATE 131 BPM、一条四段式心率区间色条、MAX HR 188 bpm、TOTAL Kcal 374、VO2 MAX 65，这些数字全程不动。底部一条深色 tab 栏（Activity / Coach / Lab / +）。整个过程 4.5 秒左右，循环描线，不切换页面。
```

**要点**
- 波形函数必须严格周期（周期 = 扫描速度 × 整数秒），否则扫回起点会看到接缝。
- 三层线：外柔光（7px 半透明）+ 主线（2.8px）+ 内高光（1.1px），是一眼显得"发光"的关键。
- 光标是径向渐变圆点，不是纯色圆。
- 周边指标一定要静止，否则抢注意力。

**注意**：波峰高度用 0–1 归一化再乘振幅，写死像素值会导致不同屏幕高度下波峰被裁。

## 04 跟手刻度轮 Dial Drag

**场景**：设置距离目标、时长目标、任何"转多少给多少"的数值。

**提示词**

```
做一个跑步 App 的「拖动圆环调距离目标」动效，深色界面（#0B0B0E）。顶部白色标题「Activity」+ 右上角小图标；下面一排年份胶囊标签（All Time / 2026 / 2025 / 2024 / 2022，All Time 为黄色实心选中态）；中间一个 348px 的环形表盘，环形外面一圈一圈排着 36 个数字刻度（0、10、20…350，贴近圆环、字号 9px），表盘中心是超大白色数字读数（54px）+ 下面一行「KM」+ 再下面一行小字「Drag wheel to adjust」+ 一个描边小按钮「DONE」。手指按住圆环上的一个白色圆点，沿圆周顺时针拖动：所有数字刻度跟着手指一起转动（角度 = 数值变化量 × 0.06 度/km），圆环外沿同步画出一条强调色进度弧，弧长跟当前数值成正比；中央数字实时跟手刷新（数值按拖动角度线性换算），拖动过程中数字纵向抖动 ±0.6px 模拟手感。拖动序列：从 900 顺时针拖到 1560（约 2.7 秒）→ 再逆时针拖回到 340（约 1.2 秒）→ 再拖回 900（约 1.4 秒），全程手指都贴在圆环上、不留断点。停止拖动后点一下「DONE」，按钮按下缩小到 0.96 倍再回弹，圆环上的进度弧停在当前比例并轻微闪一下。整个过程 6.5 秒，只播一次。
```

**要点**
- 拖动必须是**一段连续的 path**，手指全程贴环，不能拆成几段点击——否则中间的断点看起来像卡住了。
- 刻度旋转角度和数值必须是线性关系，写清"数值 × 多少度"，AI 才不会自己乱配。
- 顺时针数值增大，逆时针减小，和真实旋钮一致。

**注意**：手指坐标要按圆弧参数化（`cx + cos(θ)·r`），不要用矩形近似，否则手指会飘出圆环。

## 05 进度环填充 Progress Fill

**场景**：切换统计周期（本周 / 本月 / 今年）、切换账户、任何"同一个圆环换一组数据"。

**提示词**

```
做一个跑步 App 的「切换年份看年度跑量」动效，深色界面（#0C0C0F）。顶部白色标题「Activity」+ 右上角小图标；下面一排年份胶囊标签（All Time / 2026 / 2025 / 2024 / 2022），当前选中的一项是黄色实心胶囊、深色文字，选中态用一个能滑动的黄色胶囊块表示（宽高跟着目标标签走，切换时 0.3 秒内平移过去）。中间一个 330px 的大圆环：底环是深灰色 16px 粗，进度弧是强调色黄色 16px 粗、圆头，环外沿一圈贴 24 个小号刻度数字（0、21、42…500，字号 8px）；环中心是超大白色距离数字（52px）+「KM」+ 一行百分比小字「xx% of 500KM goal」+ 一个描边小按钮「EDIT」。点不同的年份标签时：进度弧的长度用 0.62 秒 cubic-bezier(.42,0,.58,1) 从旧比例平滑过渡到新比例（2026 只有 6%、2025 是 119% 溢出、2024 是 56%、All Time 是 180%），超过 100% 时弧画满整圈；中心距离数字同步滚动到新数值（用数字滚动而不是硬切）、文字在切换瞬间轻微模糊并淡入；环外刻度数字和底部三格指标（RUNS / AVG PACE / TIME）同时交叉淡入到新值。切换序列：All Time→2026→2025→2024→All Time，每次间隔 1 秒。整个过程 4.5 秒，只播一次，切换方向始终是「弧长平滑伸缩」，不能整块重画。
```

**要点**
- 核心是"弧长伸缩"不是"重画"：`stroke-dasharray` 从旧值插值到新值，绝对不能先清零。
- 中心数字、环外刻度、底部指标必须**同时**开始变，差半拍就散。
- 超过 100% 要有明确处理（画满整圈 / 双圈），不写清楚 AI 会画出多余的弧。

**注意**：选中的标签胶囊块宽度要跟着目标文字宽度走，写死宽度会出现胶囊比字短。

## 06 年度回顾 Recap Draw

**场景**：年度总结、里程碑回顾、任何故事式的数据揭晓页。

**提示词**

```
做一个健身 App 的「年度运动回顾」故事卡动效，米白背景（#F7F3EE）。顶部一行小字「2024 Activity Recap」+ 右上角关闭叉。第一部分：小标题「YOU REALLY WENT THE DISTANCE」，下面一个超大黑色数字「101」+ 右侧小字「km」，数字从下方 44px 处滑上来并淡入（0.5 秒）。第二部分：一条「体育场形」跑道轨道（圆角矩形的胶囊轮廓，轨道宽 262px、高 104px、描边 15px，浅米色底轨），从 0.72 倍弹性放大到 1 倍出现（0.7 秒）；然后三条彩色赛道依次沿轨道描出：蓝色（62% 弧长）、橙色（42%）、红色（26%），每条 0.78 秒、间隔 0.62 秒，从轨道左上角起笔；描完后每条赛道上浮出一个小色块标签（60.2 km / 25.8 km / 15 km）。第三部分：下方一条橙色横条（#F2762E）写着「LONGEST DISTANCE ACTIVITY / 15.07 km / on Nov 2」。第四部分：手机下半部分原本被一整块深色（#1A1512）有机水性形状盖住，形状上写着白色大字「Here's how you got there」；3.4 秒起这块深色的下边缘（一条起伏的水波曲线）自下而上抬升到画面顶部、整块退出，露出下面橙底的图标网格（6 个：60 km、21 km、15 km、3 km、1 km、1 km，每个是图标 + 数字）。网格图标在波形退开之后依次错峰弹入（每个间隔 0.09 秒，从下方 16px 处滑上来淡入）。整个过程约 5 秒，只播一次。
```

**要点**
- 三条赛道要依次描、不能同时，每条之间留 0.6 秒间隔才有"一根根画出来"的感觉。
- 最后的水波退开是整段的记忆点：形状的**下边缘**是起伏曲线，整块往上退出，不是淡出。
- 网格图标一定要等水波退开之后再出现，早了会被盖住。

**注意**：体育场形轨道的 dasharray 周长要用"矩形直边 + 两端半圆"算，直接用矩形周长会让三条线的终点错位。

## 通用注意

- 所有动效都是"触发 → 过程 → 明确的结束状态"，不要做成无限循环（心率那种实时采集除外）。
- 数字变化一律用"滚动 + 模糊"而不是直接换文本。
- 联动元素（胶囊、刻度、周边指标）必须与主元素同一拍开始变。
