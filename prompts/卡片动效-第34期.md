# 卡片动效（第34期）

第34期：一张卡从生成到收进卡包的六个瞬间。

## 01 渐变凝成卡片 Gradient Condense

做一个手机 App「开卡成功」页，单个 HTML + CSS + JS，手机竖屏 390×844，不要外部库。打开自动播放，约 2.7 秒后停在完成态。
开始是一条洋红→紫色渐变铺满整屏（390×844，无圆角）；0.2 秒起开始收拢：宽 390→300px、高 844→186px，四角 0→20px 圆角，中心从 y=422 移到 y=300，ease-in-out，耗时 1.35 秒。收到位后整张卡用 perspective(900px) 转成轻微透视：rotateY(-14deg) rotateX(-10deg) rotateZ(2deg)，耗时 0.6 秒，末尾轻微过冲再回正。
卡面内容（左上 30×24px 金色芯片、下方「•••• 4821」、底部「MAYA LIN」、右侧两个半透明白圆）在全屏阶段隐藏，收拢完成时一起淡入 0.2 秒。随后下方「你的卡已经准备好了」从下 26px 上浮淡入 0.4 秒，按钮「开始使用」晚 0.15 秒上浮 0.4 秒。
不要直接弹出卡片，必须是整块渐变收窄变薄再凝成一张卡。

## 02 扇形展开 Card Fan Out

做一个手机 App「欢迎页」的卡片扇形展开动效，单个 HTML + CSS + JS，手机竖屏 390×844，不要外部库，米白背景 #F4F3EF。
初始：5 张 142×190px、圆角 16px 的彩色卡叠在 left=124px、top=300px，每张往右下错开 2px，像厚厚一叠。下方 y=660 是「welcome!」29px 加粗，y=764 是黑底白字「OK」按钮（90×34，圆角 17px）。
0.3 秒自动开始：五张卡绕弧心 (195, 790) 展开成向上的扇形，每张的底边中点沿半径 300px 圆弧移动，中间那张 0 度不动，两侧依次 ±19 度、±38 度，每张自身也旋转同样角度，转轴是底边中点（transform-origin: 50% 100%）。错峰 0.06 秒（中间先动），ease-out，0.85 秒展开完成，展开后横跨约 370px，不能压住 y=660 的标题。2.3 秒反向收回，边缘先收、中间最后落，耗时 0.8 秒。
每张卡带 0 14px 30px 投影，最外侧的卡压在最下面。必须是一把平滑的扇，不能平移散开。

## 03 环绕旋转收合 Orbit Collapse

做一个手机 App「任务清单」开屏的卡片环绕旋转动效，单个 HTML + CSS + JS，手机竖屏 390×844，不要外部库，紫色渐变底 #7A6BF2 到 #4B3BD0。
中心 (195, 400) 有一张 184×230px 白卡（顶部 150px 彩色图块，下方「本周计划」「7 个任务 · 3 已完成」），后面藏着 6 张 104×136px 小卡（都缩到 0.34 倍，不可见）。顶部 y=88、y=122 两行白字「Get things done / with a bit more fun」。
0.3 秒自动开始：小卡散开成椭圆轨道，水平半径 170px、垂直半径 96px，均匀 6 个点，每张保持正向，从 0.34 倍放大到 1 倍，耗时 0.75 秒。随后顺时针绕 1.2 圈，总时长 1.9 秒：前 0.3 秒加速到最快，转到最下面那张（离观众最近）时明显减速，过了再加速。后半圈（y 小于中心）的卡亮度压到 0.72，最下面那张放大 1.1 倍。
2.95 秒开始收拢：轨道半径缩到 22%，卡片缩到 0.48 倍并压到主卡后面，耗时 0.65 秒；最后主卡放大 1.02 倍再回正。必须真的缩进主卡后面，不能凭空淡出。

## 04 下滑收进卡堆 Swipe to Deck

做一个手机 App「卡片池」的向下滑收进卡堆动效，单个 HTML + CSS + JS，手机竖屏 390×844，不要外部库，深色底 #0E1116。
顶部「今日推荐」22px 白色加粗，右上「卡片池 3」12px 灰色。大卡 318×396px、圆角 24px，放在 left=36px、top=158px：顶部 186px 橙红渐变图，下方标题「海岸线 3 日」、副标题「自驾 · 海景 · 露营」、三行浅色占位条、底部绿色「¥ 1,280」。底部 y=742 是 260×64px 卡堆容器（圆角 20px、半透明描边），内含 3 张 46×46 色块错开叠着，右侧写「卡堆」和数字「3 张」。
0.45 秒手指按住大卡往下拖 0.85 秒：卡片跟着下移 300px（top 158→458），同时缩到 0.52 倍、逆时针歪 8 度，ease-in-out。1.30 秒落到卡堆上方时，卡堆横向放大 1.06、纵向压到 0.90，再用 0.4 秒弹回 1 倍（带过冲）；落下的卡在 0.18 秒内缩到 0.2 倍淡出，不要塞进 64px 高的卡堆。
随后卡堆数字 3 跳到 4 并放大 1.34 倍、变绿，上方飘起绿色「+1」上移淡出；备卡「城市周末」从上方 22px、0.93 倍用 0.65 秒推上来补位。

## 05 卡堆展开成列表 Stack to List

做一个手机 App「自动缴费」页的卡堆展开成列表动效，单个 HTML + CSS + JS，手机竖屏 390×844，不要外部库，浅底 #F7F7F9。
顶部 y=60「自动缴费」24px 加粗，y=95「4 笔 · 每月 8 号」12px 灰色。中部是 4 张 320×86px 白卡（圆角 18px、投影 0 8px 20px），都叠在 (35, 200)，每张往右下错开 11px、缩小 2%，只露出顶卡的完整内容和下面几张的边；卡内是左侧 42×42 圆角图标、中间「电费 / 每月 8 号」、右侧「¥ 128.00」和绿色「已开启」胶囊。
0.25 秒起整理：顶卡每 0.43 秒抬起一次（上移 38px、放大 1.05 倍，单次 0.30 秒内完成），同时下一张补到顶上、抬起的卡落回最下面；循环三次，1.54 秒结束。
1.55–2.45 秒展开：四张卡依次下移到 y=200 / 296 / 392 / 488（行距 96px），每张单卡 0.62 秒，从上往下错峰 0.07 秒起跑，同时从缩小状态回到 1 倍。必须是同一批卡从一叠变成一行，不能换新卡；叠着时后面的卡只露边，不能几个标题叠在一起。

## 06 拍立得洗牌 Polaroid Shuffle

做一个手机 App「整理照片」页的拍立得洗牌动效，单个 HTML + CSS + JS，手机竖屏 390×844，不要外部库，浅灰白底 #EFF1F4。
顶部 y=70「整理照片」24px 加粗，y=104「正在识别 6 张」12px 灰色。中部 6 张 220×268px 拍立得卡（圆角 4px、白色卡纸、内侧 200×200px 照片区 + 底部标签：海边 / 咖啡馆 / 日落 / 街道 / 雪山 / 早餐）叠在 (85, 230)，每张往右下错开 6–9px、旋转 ±6 度、缩小 2%。底部 y=762 一条 270×4px 进度条。
0.1 秒起循环，周期 3.36 秒，每 0.56 秒抽一次牌：顶卡先上移 40px（0.16 秒），再绕 Y 轴摆 26 度（父级 perspective(800px)，左右交替，0.3 秒），边摆边往右下插到最下面；同时下面 5 张并行补位，每张错峰 0.03 秒、整体 0.39 秒完成（不要排队，会超过 0.56 秒周期）。插到底的那张落位前轻微回弹。最上面的卡投影最重（0 22px 44px），越往下越轻。
顶部状态文字每 1.12 秒换一次「正在扫描… / 正在识别物体… / 正在整理…」，进度条 3.36 秒线性填满后归零。必须是同一摞卡循环换位，被抽出的那张路径要连续，不能瞬移。
