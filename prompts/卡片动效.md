# 卡片动效 · 4 个提示词

对应抖音视频：4个卡片动效，让App和小程序一点就有手感

不想装 skill？直接复制下面的提示词发给 AI 编程工具（Claude Code / Codex / Cursor 等）就能用。

每个都附了"常见写法"，对比一下就知道差在哪：只说一句需求，AI 多半不会做出跟手的细节。

---

## 01 按下微倾（Press Tilt）
常见写法：做一个购物 App 的商品卡片列表，手指按下卡片时要有反馈 → 待实测校正

```
做一个购物 App 的商品卡片按压反馈，像手按在一块软垫上：手指按住卡片时，卡片朝按下的那一侧轻轻往下压（按左边左边沉，按右边右边沉，最多倾斜约 8°），同时整张缩小到 0.97 倍，表面有一道很淡的反光跟着手指位置移动；按着不松左右移动，倾斜方向跟着手指变；松手后卡片带一点回弹恢复平整（约 400ms）再进入详情；只动 transform，用 perspective 做立体感；按 390×844 手机尺寸。
```

## 02 卡片翻面（Flip Card）
常见写法：做一个背单词卡片，点一下可以翻到背面看中文释义 → 待实测校正

```
做一个背单词 App 的单词卡翻面，像翻一张扑克牌：正面是大号英文单词 + 音标 + 一张插图，背面是中文释义 + 例句；点一下卡片绕竖轴翻到背面，翻到一半（卡片侧立、转到 90°）的那一刻微微抬起放大到最大 1.05 倍、阴影变大变淡，抬起和翻转同步进行，后半程翻完落回原样并带一点回弹（共约 600ms）；翻的过程中正反两面不会同时露出来（backface-visibility: hidden）；再点一下翻回正面；底部"认识 / 不认识"两个按钮只在翻到背面后才浮上来；按 390×844 手机尺寸。
```

## 03 吸附轮播（Snap Carousel）
常见写法：做一个旅行 App 首页的横向推荐卡片轮播 → 待实测校正

```
做一个旅行 App 首页的横向推荐卡片轮播，像转盘停在格子上：卡片横排一行，正中一张完整、左右各露出一截；手指拖动时卡片跟手走，松手后按甩的快慢再滑一段，然后自动吸到最近的一张停在正中；正中那张 1 倍大、完全清楚，两边的缩到 0.88 倍、略微变暗，滑动过程中大小和亮度跟着位置连续变化，不是停下才跳；下方小圆点指示当前第几张，当前点拉长成胶囊；按 390×844 手机尺寸。
```

## 04 长按浮起（Long-press Lift）
常见写法：做一个笔记列表，长按卡片弹出菜单（收藏、分享、置顶、删除） → 待实测校正

```
做一个笔记 App 列表的长按卡片菜单，像从桌上把一张牌拿起来：手指按住卡片约 0.4 秒，卡片先轻轻缩到 0.97 倍（蓄力），然后浮起放大到 1.04 倍、阴影变大变远，同时背后整页虚化压暗；卡片下方弹出一个圆角菜单（收藏、分享、置顶、删除，删除用红色），菜单从卡片边缘展开并带一点回弹；手指不松直接滑到菜单项上会高亮，松手就执行；点空白处卡片落回原位、背景恢复清晰；按 390×844 手机尺寸。
```
