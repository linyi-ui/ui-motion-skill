# 选择器动效 · 4 个提示词

对应抖音视频：第18期 4个选择器动效

不想装 skill？直接复制下面的提示词发给 AI 编程工具（Claude Code / Codex / Cursor 等）就能用。

每个都附了"常见写法"，对比一下就知道差在哪：只说"做个数量加减/价格筛选/日期选择"，AI 多半做成数字直接换、一格一格跳、平平的列表。

---

## 01 数量加减（Stepper）
常见写法：做一个购物车商品数量加减 → 数字一下子就换了，没有翻动的过程，按住也不会连着加

```
做一个购物车数量加减器：点 + 或 − 时，按钮按下缩小到 0.9 再弹回；数字像翻页计数器一样，加的时候旧数字向上滑出、新数字从下方滑入，减的时候方向相反，用时约 220ms；数量到 1 时 − 按钮变灰；长按 + 超过 0.5 秒后越加越快连续增加。
```

## 02 双头价格滑块（Range Slider）
常见写法：做一个价格区间筛选 → 把手一格一格地跳，按上去没反应，价格直接蹦出来

```
做一个商品价格区间双头滑块：两个圆形把手可以分别拖动，拖动时把手放大到 1.2 倍并跟手移动，两个把手之间的轨道用强调色填充、实时跟着变长变短；把手上方浮出价格气泡，数字实时变化，两个气泡靠近时自动错开不重叠；两个把手不能交叉，至少保持 100 元间隔；松手时把手弹性回到正常大小，并吸附到最近的 50 元刻度。
```

## 03 日历选区间（Date Range）
常见写法：做一个酒店入住离店日期选择 → 要点两下，选好的那段一下子全亮，没有一路涂过去的感觉

```
做一个订酒店用的日历区间选择：点第一天作为入住，日期变成实心圆；手指按住往后滑动时，从入住日到手指所在日期之间的格子像荧光笔一样依次涂上浅色底带，带子两端是圆角；松手确定离店日，底部实时显示「共 N 晚」，数字滚动变化；如果新选的日期早于入住日，就自动当成新的入住日重新开始。
```

## 04 滚轮选择器（Wheel Picker）
常见写法：做一个生日选择 → 要么是长长的下拉框，要么是平平的列表，没有甩一下咔哒停住的手感

```
做一个生日滚轮选择器：年、月、日三列滚轮，手指上下拖动时跟手滚动，松手后带惯性继续滚，再减速并吸附到最近的一格停稳，有咔哒感；中间选中行文字最大最亮，越往上下越小越透明，带3D 圆柱弯曲效果；月份变了以后日期列的天数自动更新（如 2 月只有 28 或 29 天）。
```
