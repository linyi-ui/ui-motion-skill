# 弹窗与菜单动效 · 4 个提示词

对应抖音视频：4个弹窗与菜单动效，让App和小程序的弹窗菜单有质感

不想装 skill？直接复制下面的提示词发给 AI 编程工具（Claude Code / Codex / Cursor 等）就能用。

每个都附了"常见写法"，对比一下就知道差在哪。

---

## 01 确认对话框（Confirm Dialog）
常见写法：做个删除确认弹窗 → 多半是 display 啪一下出现、无遮罩无背景模糊、无缩放回弹，甚至直接调系统 confirm()

```
做一个删除确认对话框：点「删除」后，先给整个页面盖一层半透明黑色遮罩并对背景加 8px 高斯模糊，遮罩淡入约 200ms；对话框从屏幕正中心以 scale 0.8→1 弹性放大、带轻微过冲回弹（cubic-bezier(.34,1.56,.64,1)、约 260ms）并淡入；点取消或遮罩时对话框 scale 回 0.9 + 淡出、背景模糊解除。不要啪一下直接显示、背景不变暗。
```

## 02 下拉操作菜单（Popover Menu）
常见写法：做个更多菜单 → 多半缺 transform-origin，菜单从屏幕中间或正中放大蹦出、跟按钮没关系，菜单项也不错落

```
做一个下拉操作菜单：右上角「⋯」按钮，点击后菜单锚定在按钮正下方、右对齐，transform-origin 设为右上角（top right），以 scale 0.85→1 + 淡入展开约 180ms；菜单项再以 8ms 间隔逐条淡入 + 上移 6px 形成错落。点菜单外收回淡出。不要从屏幕中间蹦出、不要所有项一起出现。
```

## 03 长按上下文菜单（Context Menu）
常见写法：做个长按弹出的菜单 → 多半没有卡片浮起 + 背景模糊压暗的层次感，也没有 haptic 抖动，菜单常跑到屏幕中间

```
做一个长按上下文菜单：长按卡片 400ms 触发——卡片 scale 1→1.04 浮起、阴影加大并抖一下做触感反馈，同时背景加 12px 模糊 + 压暗（卡片本身保持清晰）；上下文菜单从卡片正下方、transform-origin 顶部中心 scale 0.9→1 弹性弹出约 220ms。松手点任意处则卡片缩回、菜单淡出、背景恢复。不要直接套系统右键、不要光秃秃一个框。
```

## 04 底部操作表（Action Sheet）
常见写法：做个分享面板 → 多半把 display 和 transform 放同一帧导致上滑被跳过直接蹦出，或只用 opacity 淡入没有上滑，选项也不错落

```
做一个底部操作表：点「分享」后，从屏幕底部升起操作表，背景盖遮罩淡入；操作表整体 translateY 100%→0 上滑进入（cubic-bezier(.32,.72,0,1)、约 300ms）；里面每个选项再以 30ms 间隔依次淡入 + 上移 10px 错落登场。点取消或遮罩则 translateY 0→100% 滑出 + 遮罩淡出。不要直接蹦出来、不要只淡入不上滑。
```
