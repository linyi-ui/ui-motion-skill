# 搜索筛选动效 · 4 个提示词

对应抖音视频：第17期 4个搜索筛选动效

不想装 skill？直接复制下面的提示词发给 AI 编程工具（Claude Code / Codex / Cursor 等）就能用。

每个都附了"常见写法"，对比一下就知道差在哪：只说"做个搜索/筛选/排序"，AI 多半做成点一下就硬切、松手才跳位置。

---

## 01 搜索框展开（Search Expand）
常见写法：点搜索图标能展开搜索框 → 直接跳一个新搜索页面，图标和框完全对不上

```
做一个商品搜索首页，点搜索图标能展开搜索框：像搜索框自己从图标里长出来——点击右上角搜索图标时，图标原地展开成通栏输入框（位置、宽高都做过渡，不是切换），背景同时渐渐压暗，下方弹出搜索历史和热门搜索词；点返回按同样路径收回原位。
```

## 02 热门标签联想（Suggestion Chips）
常见写法：输入文字时下面要有联想词 → 打完字停一下，联想词全部一起闪一下刷新

```
做一个搜索中间页，输入文字时下面要有联想词：像边写边冒泡，词一个个蹦出来——每打一个字，联想词列表按新的匹配结果实时增删：新出现的词从右侧滑入淡入，不再匹配的词向左缩小淡出，是逐条变化，不是整体刷新。
```

## 03 筛选面板滑出（Filter Panel）
常见写法：点筛选按钮能弹出筛选面板 → 面板直接出现在原地，滑块也要松手才跳到新位置

```
做一个商品列表页，点筛选按钮能弹出筛选面板：像从门缝里拉出一块抽屉——点击筛选按钮，面板从屏幕右侧滑入（带一点轻微回弹），背景同时压暗；面板里拖动价格区间滑块时数值和滑块位置跟手实时变化；点确定时面板按同样路径滑回收起。
```

## 04 结果排序切换（Sort Switch）
常见写法：点排序方式能切换商品顺序 → 点一下整个列表瞬间重排，卡片直接跳过去，中间闪一下

```
做一个商品列表页，点排序方式能切换商品顺序：像卡片自己排队走到新位子——点击排序方式（如价格从低到高），列表里每张商品卡片都平滑移动到按新顺序该在的位置（真实的位置过渡动画），不是重新生成一遍列表或者直接跳转。
```

---

小提示：想要更像手机 App，可以在最后加一句"深色主题，按 390×844 手机尺寸，用 Pointer Events 实现，鼠标和手指都能拖"。

装了 skill 的话，直接说"用 ui-motion 做一个搜索框展开"即可，AI 会按动效库里的完整参数实现。
