# 个人主页动效 · 6 个提示词

对应抖音视频：6个主页动效，让App用起来像真产品

不想装 skill？直接复制下面的提示词发给 AI 编程工具（Claude Code / Codex / Cursor 等）就能用。

每个都附了"常见写法"，对比一下就知道差在哪：只说"主页加点动画"，AI 多半给你一个全局淡入。

---

## 01 头像堆叠展开（Avatar Stack）
常见写法：头像一排排淡入，然后一直静止

```
做一个个人主页首屏的头像堆叠效果。浅暖灰底（#F4F2EE），页面上半部散落 10–14 个圆形头像气泡，直径 52–90px，位置错落不要排成网格，每个外面一圈 3px 的底色描边和柔和投影，其中夹 4 个白底话题小气泡（如「聊聊钱」）。循环动画：每个头像按 2.6 秒周期错峰（相邻错开 0.3–0.4 秒）做「缩退 → 空一拍 → 弹入」——缩退用 0.3 秒 ease-in-out 缩到 0，空 0.3 秒，再用 0.55 秒弹簧曲线弹回（先过冲到 1.06 倍再回落到 1），进出时周围最近的 2–3 个气泡被挤开 4–6px 再慢慢落回原位。新话题气泡用 0.4 秒从 0.6 倍弹到 1。页面下方保留两行大标题和一个黑色圆角按钮，不要跟着动。整体节奏慢一点、呼吸感强，不要全部同时闪。
```

## 02 关注按钮变形（Follow Morph）
常见写法：点关注 → 按钮直接换成"已关注"三个字

```
做一个个人主页的关注按钮变形动效，深色页面（#0B0B0D）。按钮是 132×44 的圆角胶囊，强调色底、深色字「+ 关注」。点击后按顺序发生：0–0.1 秒按钮整体压到 0.86 倍；0.08 秒起从按钮中心炸出 8 个小圆角色（14px，带两个小黑点当眼睛），向四周弹开约 55–60px，每个延迟错开 0.03 秒，飞行中各自旋转、先放大再缩小；0.56–0.85 秒角色回收消失；0.74–0.94 秒按钮底色过渡成深色、加一圈强调色细描边，文字换成白色「✓ 已关注」；同时右侧关注数从 1,248 滚到 1,249——数字要在 0.5–0.86 秒之间向上滚动一格，中间带一点模糊，停下必须完全清晰。整个过程约 1.2 秒，只播放一次，不要循环。
```

## 03 粉丝数翻滚（Follower Ticker）
常见写法：数字直接从 12800 跳到 13500

```
做一个粉丝数增长的数字翻滚动效，深色卡片（#17191F，圆角 28px）。卡片中央一行 5 位超大数字（字号约卡片宽的 27%，等宽数字、字重 900），上方一行小字「本月新增关注」，左右两侧各一个 − / + 圆形按钮，下方一排 4 个范围胶囊（今天 / 本周 / 本月 / 全部）。点 + 后：旧数字向上滚出、新数字从下方滚入，滚动时长 0.34 秒，滚动到一半时加约 6px 的竖向运动模糊，停稳后必须完全清晰、边缘锐利；数字从 12800 变到 13500（每位独立滚动，进位时高位也要动）。同一时间范围胶囊从「本周」切到「本月」：选中态变成强调色底、深色字，切换带 0.22 秒的轻微回弹（先到 1.06 倍再回落）。+ 按钮按下时缩到 0.94 倍再弹回。
```

## 04 封面视差收起（Cover Collapse）
常见写法：上滑 → 封面整块直接滑走，资料区突然顶到最上面

```
做一个个人主页的封面视差收起动效，深色页面。顶部是一张 390×260 的大封面（强调色渐变 + 超大英文标题），下方是头像、名字、简介和作品网格。手指向上滑动时：整页内容上移，封面额外以 0.45 倍的慢速跟随（视差），封面高度同步从 260px 收到 88px；封面里的大英文标题缩小到 0.42 倍并淡出，收到 88px 时顶部换成一条细栏（背景深色、底部一条细分割线、左边小号英文标题淡入）。收起总时长 1.0 秒，缓动 ease-in-out，资料区上移贴到细栏下面。手指向下滑动时完整反向还原，封面重新长高、大标题放大回来，所有位置和透明度都要连续、不能跳变。
```

## 05 简介就地编辑（Inline Edit）
常见写法：点简介 → 弹出一个新的编辑页面，改完再退回来

```
做一个个人主页简介的就地编辑动效，深色页面。简介是一段两行的普通文字，字号 15px、行高 25px、灰色。点一下简介区域后：0.05–0.35 秒外框从文字块四周长出来（1.5px 强调色描边 + 5% 白色底的圆角块，圆角 14px），同时底部内边距略微增加；0.78–1.16 秒 iOS 键盘从屏幕底部升上来（带轻微过冲），编辑区自动上移让光标可见；1.15–2.3 秒新简介逐词替换（每 0.06 秒出现一个词，直接显示不要淡入，光标在末尾闪烁）。2.5 秒点「保存」按钮：按钮先按下缩小，然后文字变白、外框收回、键盘降下（2.66–3.02 秒），3.72 秒起在按钮位置轻轻弹出一个「✓ 已保存」小胶囊。整个过程可逆，点「取消」要完整还原成原来的普通段落。
```

## 06 上传进度环（Upload Ring）
常见写法：上传时转一个圈，进度数字直接跳到 100%

```
做一个上传头像的进度动效，深色页面。阶段一：屏幕中间一行小字「正在上传头像」，下方一条 240×10 的进度胶囊，胶囊在 1.35 秒内从左到右填满（强调色），下方百分比同步从 0% 走到 100%，节奏是先快后慢。填满后 0.24 秒内文案交叉淡出换成「全部准备就绪」。阶段二：整屏溶解进个人主页（0.5 秒，缩放从 1.04 到 1）。主页中央一个直径 172px 的圆环：底环是 9% 白色的细环，强调色的进度弧从 12 点方向顺时针画出来，1.5 秒内画到 68%，端点圆头，环里的大数字百分比同步从 0% 涨到 68% 并停在同一个数。圆环下面依次是头像、名字、三格数据卡和一个强调色圆角按钮。
```
