# 评论区动效 · 3 个提示词

对应抖音视频：第11期 3个评论区动效

不想装 skill？直接复制下面的提示词发给 AI 编程工具（Claude Code / Codex / Cursor 等）就能用。

每个都附了"常见写法"，对比一下就知道差在哪：只说"评论能 @ 好友 / 能展开回复 / 能长按回应"，AI 做出来功能都有，但名单、回复、表情都是"啪"一下冒出来的。

---

## 01 @好友联想（Mention Picker）
常见写法：做一个评论输入框，输入 @ 可以选择好友 → 名单直接冒出来，选完 @昵称 是普通文字，删的时候一个字一个字退

```
做一个评论区的 @好友联想，像从光标里抽出一张名单：在输入框里打出"@"时，好友列表从光标位置往上弹出来（约 200ms，带一点回弹），每行有头像、昵称和一行小字；继续打字时列表实时筛选，不匹配的行收起淡出，剩下的往上补位，匹配的字高亮；点选后"@昵称"变成一个强调色小胶囊插进文字里，光标跳到胶囊后面；按删除键时整个胶囊一次删掉，不要一个字一个字删；按 390×844 手机尺寸。
```

## 02 展开楼中楼（Thread Expand）
常见写法：做一个评论列表，每条评论下面有回复，可以点击展开 → 12 条回复一整块直接蹦出来，下面的评论被"咔"地顶下去

```
做一个评论区的楼中楼展开，像拉开一串挂起来的灯：一级评论下面显示"展开 12 条回复"，点击后回复一条接一条从上往下垂下来（每条间隔约 70ms，带淡入和轻微下落），左边一条细竖线跟着往下长，把它们连起来；下面的评论平滑往下让位，不要一下跳开；展开后文字变成"收起"，小箭头转 180°；点收起时回复从下往上依次收回，竖线跟着缩短；按 390×844 手机尺寸。
```

## 03 长按表情回应（Reaction Picker）
常见写法：做一个评论区，长按评论可以选择表情回应 → 表情条直接冒出来，还得松手再点一下，点完数字直接变

```
做一个评论区的长按表情回应，像放大镜扫过一排表情：长按一条评论约 400ms，评论轻微缩小下沉，上方弹出一条圆角表情栏（❤️😂😮😢👍🔥），6 个表情依次弹出；手指不松开左右滑动，滑到哪个表情，哪个就放大到约 1.8 倍并往上跳一点，旁边的稍微放大；松手后选中的表情沿弧线飞到评论下方，落进回应小标签，计数 +1 并跳一下；按 390×844 手机尺寸。
```
