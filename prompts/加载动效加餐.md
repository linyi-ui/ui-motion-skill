# 加载动效加餐 · 4 个提示词

第12期最初准备的 4 个加载动效，场景偏专门（AI 出图、应用商店、视频播放器、外卖订单），正片换成了更常用的 4 个，这 4 个放这里当加餐，同样实测过，直接复制就能用。

不想装 skill？直接复制下面的提示词发给 AI 编程工具（Claude Code / Codex / Cursor 等）就能用。

---

## 01 AI 出图显影（AI Image Generating）
常见写法：做一个 AI 画图 App，生成图片时显示加载进度

```
做一个 AI 绘图 App 生成图片时的加载，像冲洗照片一样慢慢显影：点"生成"后图片框立刻出现，尺寸固定、版面不跳；框里先是一层半透明的细密彩色噪点在轻轻流动，透过它能隐约看到底下的模糊色块；随着进度，噪点一点点退去，画面从模糊的大色块慢慢变出清晰细节，同时从 1.03 倍缓缓缩回 1 倍；图片下方一条细进度条和三个阶段文字"构图 → 上色 → 细节"，走到哪个阶段哪个变亮，这个阶段走完再打勾；完成时图片清晰定格，边框轻轻闪一下，下方出现"保存""再来一张"按钮；用一个按钮模拟约 5 秒的生成；按 390×844 手机尺寸。
```

## 02 图标扇形下载（App Icon Download）
常见写法：做一个应用商店的下载按钮，点了显示下载进度

```
做一个应用商店点"获取"后的图标下载，像钟表指针扫一圈：点按钮后按钮缩成一个圆形进度环；App 图标立刻出现但整体变灰变暗，图标上一块扇形亮区从 12 点方向顺时针扫开，扫到哪图标就亮到哪；下载完成时扇形扫满，图标恢复全彩并轻轻弹一下（放大到 1.1 倍再回弹），图标下的名字从"下载中…"变成 App 名；下载中点一下图标可以暂停，扇形停住并显示暂停图标，再点继续；模拟约 4 秒下载；按 390×844 手机尺寸。
```

## 03 视频缓冲（Video Buffering）
常见写法：做一个视频播放器，网速慢的时候显示缓冲

```
做一个视频 App 的播放缓冲，像人走在提前铺好的路上：进度条分三层——灰色底、浅白色"已缓冲"段跑在播放头前面、强调色的已播放段；网速好时缓冲段一直领先播放头一小截（约 1 秒）；网速变慢时缓冲段几乎不动，被播放头追上，这时画面停在当前帧、不黑屏，轻轻压暗一点，中间出现一个半透明小圆圈在转，不要大白框；缓冲够了小圆圈淡出、画面亮回来接着播；用一个按钮模拟网速变慢 2 秒；按 390×844 手机尺寸。
```

## 04 外卖接力进度（Order Progress）
常见写法：做一个外卖订单页，显示配送进度

```
做一个外卖订单页的配送进度，像接力赛一棒传一棒：横向 4 个节点"已下单 → 商家接单 → 骑手取餐 → 已送达"，节点之间用连线连起来；推进时当前这段连线从左往右慢慢走满（约 600ms），走到下一个节点时，节点从灰色空心圆变成强调色实心圆并打勾，弹一下（放大到 1.2 倍再回弹）；正在进行的节点外面有一圈慢慢呼吸的圆环；上方的大字状态和预计送达时间跟着换，文字上下滑动切换；用一个按钮一步步推进；按 390×844 手机尺寸。
```

---

装了 skill 的话，直接说"用 ui-motion 做一个 AI 出图显影"即可，AI 会按动效库里的完整参数实现。
