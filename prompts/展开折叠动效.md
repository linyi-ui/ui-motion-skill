# 第21期 · 4 个展开折叠动效（让 App 和小程序展开收起都顺滑不卡顿）

对应抖音视频：4种展开折叠动效，让App和小程序展开收起都顺滑

不想装 skill？直接复制下面的提示词发给 AI 编程工具（Claude Code / Codex / Cursor 等）就能用。

每个都附了"常见写法"，对比一下就知道差在哪。

---

## 01 手风琴展开（Accordion）
常见写法：做一个 FAQ，点标题能看到下面的答案 → 多半是直接显隐，没有高度过渡，箭头也不转

```
做一个 FAQ 常见问题列表的手风琴展开：点击某一项时，它下面的答案区域高度从 0 平滑地撑开（不是瞬间显示出来），右侧的箭头同时旋转 180 度；而且同一时刻只展开一项，点开新的一项时，之前展开的那项会自动平滑收起。手机竖屏，面板展开约 300–400ms，ease-out，箭头旋转同步。
```

## 02 展开全文（Read More）
常见写法：做一段长文，能点展开全文看全部 → 多半是瞬间把全文显示出来，页面猛地变长

```
做一个图文笔记的「展开全文」：长文默认只显示 3 行，末尾带「...展开全文」，点击后文字区域的高度平滑地向下撑开显示全部内容（不是一下子全蹦出来），按钮文字变成「收起」、箭头翻转；再点一下又平滑地收回 3 行。手机竖屏，高度过渡约 350–450ms，ease-out。
```

## 03 卡片放大详情（Expand to Detail）
常见写法：做一个商品列表，点一个能看详情 → 多半是直接跳转到新页面，没有过渡动画

```
做一个商品列表点进详情的「卡片放大过渡」：点击列表里的一张卡片时，这张卡片会平滑地放大、位置连续地移动，最后铺满整个屏幕变成详情页（图片是同一张，全程连续，不是跳转到一个新页面），点返回时再平滑地缩回到它在列表里原来的位置。手机竖屏，放大/缩回约 450–550ms，ease-in-out，详情内容放大到位后再淡入。
```

## 04 底部抽屉拖拽（Drag Sheet）
常见写法：做一个底部弹出的面板，能打开和关闭 → 多半只有打开/关闭两个状态，不能跟手拖，一下弹到底

```
做一个底部可拖拽的抽屉面板：手指按住把手拖动时，抽屉跟着手指上下实时移动（跟手，不是点一下才弹出），松手时自动吸附到最近的档位——收起 / 半展开 / 全展开，并带一点回弹，不会停在中间尴尬的位置。手机竖屏，用 Pointer Events 实现，松手吸附约 300–400ms 带轻微回弹（超调不超过 8%）。
```
