# 图片查看 · 4 个提示词

对应抖音视频：4种图片查看动效，让App看图更顺手

不想装 skill？直接复制下面的提示词发给 AI 编程工具（Claude Code / Codex / Cursor 等）就能用。

每个都附了"常见写法"，对比一下就知道差在哪：只说一句需求，AI 多半不会做出跟手的细节。

---

## 01 点开放大（Tap to Zoom）
常见写法：做一个图片社区的作品列表，点一张图能查看大图 → 实测多数直接跳转到新页面，没有位置过渡

```
做一个图片社区的作品列表，点一张图能查看大图：像图片自己长大撑满屏幕——点击小图时，图片从小图所在的原始位置和大小开始，连续放大到铺满全屏（位置、宽高都做过渡，不是切换），背景同时渐渐压暗；点右上角关闭按钮按同样的路径缩回原位。
```

## 02 双指缩放（Pinch to Zoom）
常见写法：做一个商品详情页，图片要支持放大看细节 → 实测多数只支持双击缩放，双指捏合完全无效

```
做一个商品详情页，图片要支持放大看细节：像拿着照片怎么凑近看都行——双指在图片上一撑一收，以两指中点为中心连续缩放（可放大到约 3 倍）；放大后能用手指拖动平移查看细节；双击图片在放大和还原之间快速切换，还原时带一点回弹。
```

## 03 下滑关闭（Swipe Down to Dismiss）
常见写法：做一个相册App，全屏看图时能关闭返回列表 → 实测多数下滑过程没有任何跟手变化，松手瞬间才突然消失

```
做一个相册App，全屏看图时能关闭返回列表：像捏着照片把它放下去——手指在大图上向下拖动，图片跟手一起缩小、四角圆角跟着变大，背后遮罩透明度跟着降低；松手时如果拖动距离超过阈值就继续缩小淡出、关闭返回列表，没超过阈值就用弹簧动画弹回铺满全屏的状态。
```

## 04 多图左右滑（Gallery Swipe）
常见写法：做一个商品详情页，多张图能左右切换着看 → 实测多数滑动卡顿，松手直接跳转，没有中间过渡

```
做一个商品详情页，多张图能左右切换着看：像甩一张照片滑到下一张——全屏看图时左右拖动，图片跟手一起横向偏移；松手时根据拖动距离决定直接翻到下一张（弹簧滑动完成）还是弹回当前这张；底部用一排圆点显示第几张，当前这张对应的圆点要拉长、变成强调色。
```
