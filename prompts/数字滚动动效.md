# 第22期 · 4 个数字滚动动效（让 App 和小程序的数字滚得高级）

对应抖音视频：4种数字滚动动效，让App和小程序数字滚得高级

不想装 skill？直接复制下面的提示词发给 AI 编程工具（Claude Code / Codex / Cursor 等）就能用。

每个都附了"常见写法"，对比一下就知道差在哪。

---

## 01 金额平滑滚动（Count-up Rolling）
常见写法：做一个钱包余额，收款后余额更新成新的数 → 多半是啪一下直接换成新值，看不到涨了多少

```
做一个钱包余额的数字滚动：点「收款」后，大号余额数字从旧值平滑滚动增长到新值，用 easeOutCubic 缓动、约 1.1 秒，整数部分带千分位逗号分组（如 8,860），滚动结束时稳稳停住不抖动，不要啪一下直接替换。
```

## 02 点赞数翻滚（Odometer Roll）
常见写法：做一个点赞按钮，点一下点赞数加一 → 多半是整个数字一起换掉或一起闪，没有"只翻变化那一位"

```
做一个点赞数的里程表翻滚：点赞 +1 时，每一位是一列 0-9 的数字条，只有发生变化的那一位向上滚动一格（带一点弹性过冲），其它位保持不动；进位时高位跟着滚动（如 1299 → 1300）。不要整个数字一起闪或直接替换。
```

## 03 积分庆祝累加（Score Ticker）
常见写法：做一个任务完成页，显示这次拿到的积分 → 多半是数字线性涨到头就僵住，没有放大回弹和庆祝

```
做一个任务积分的庆祝式累加：积分从 0 先快后慢在 0.9 秒内滚到目标值，期间数字高频跳动；到达目标那一刻整个数字放大到 1.15 倍再 spring 回弹到原大小，同时一圈环形进度从 0 画满、迸发少量庆祝粒子，做出「达成」的爽感。
```

## 04 统计数字入场（Stat Count-in）
常见写法：做一个数据统计卡，显示步数、卡路里、天数 → 多半是数字一进页面就是静止的最终值，没有入场滚动

```
做一个数据统计卡的入场动画：页面进入时，几个统计数字同时从 0 滚动到各自目标值，用 easeOutBack（带轻微过冲回弹）、约 1 秒，大数字带千分位逗号，到顶轻微回弹后定格，不要一进来就是静止的最终数字。
```
