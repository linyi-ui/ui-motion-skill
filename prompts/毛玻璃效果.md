# 毛玻璃效果（GLASS）提示词

App 里的毛玻璃质感——背后实时模糊、边缘高光、明暗过渡。这一类最容易被做成"一块半透明灰"，关键差别在于**背后是不是实时的内容**。

适用于：修图 App 的调整面板、夜间地图的浮动底栏、阅读页的文字放大镜、水平仪类工具。

---

## 01 毛玻璃浮层（Glass Panel）

做一个手机修图 App 的毛玻璃调整面板。照片铺满整屏；用户点底部工具条的「调整」，面板从屏幕底部浮上来（高约 340px、顶部圆角 30px、0.45 秒 ease-out，末尾带 8px 过冲后回位）。

面板必须是真毛玻璃：面板背后是同一张照片的**实时模糊副本**（模糊 16px、饱和度 1.1、亮度略降），上面再叠一层深色半透明（约 45%）和从顶部往下渐隐的白光；面板顶边有一道 2px 白色高光，四周 1px 浅描边。**不要用一张固定模糊图片冒充**，面板一移动，背后露出的内容就跟着变。

面板里四行参数（亮度 / 对比度 / 饱和度 / 锐化）**错开落下**：每行间隔 0.075 秒、各自从下方 16px 淡入，不要一起出现。

拖动亮度滑杆：滑钮实时跟手、左侧强调色填充跟着长、右侧数值每帧同步刷新，同时**整张照片的亮度实时跟着变**。

点「收起」：面板在 0.4 秒内滑回屏幕外，滑出时有一点加速，不要淡出。

## 02 毛玻璃底栏（Glass Dock）

做一个手机夜间城市页的毛玻璃底栏。底部浮着一条 338×64px 的玻璃胶囊（圆角 32px），背后是同一张城市照片的**实时模糊副本**（模糊 18px、亮度压到 0.62），再叠一层很淡的深色和白色渐变，边缘 1px 浅描边 + 顶部 1px 内高光，像一块真的磨砂玻璃。

1）横滑：四个图标（搜索 / 日历 / 月相 / 设置）一边向左退出、一边淡出；同时一行状态文字从右侧滑入（当前天气 + 地点），两段不能同时一起亮着，必须有明显的前后交接。
2）点日历：一块玻璃月相面板从底部升起（高 400px、顶部圆角 30px、0.6 秒 ease-out），面板同样是照片的实时模糊副本；底栏同时上移 118px 让位。
3）面板里 7×4 个月相圆点，选中那一个轻轻放大一下。
4）下滑收起：面板滑回屏幕外，底栏在 0.55 秒内落回原位，落下时带一次约 10px 的回弹过冲。

## 03 毛玻璃放大镜（Glass Loupe）

做一个手机阅读页的毛玻璃放大镜。正文是深色页面上的多行文字。

用户长按某一行（约 0.4 秒）：一个直径 150px 的圆形玻璃泡从手指上方浮出来，从 0.5 倍放大到 1 倍（0.35 秒 ease-out）。泡里显示的是**同一段正文的 2 倍放大**，并且放大中心始终对准手指按住的位置——手指移动，泡里的内容跟着反向平移，不能偏移。

玻璃质感：泡内内容是清晰的（不要整块模糊），泡内叠一层斜向白光渐变（左上强、右下弱，约 30% 不透明度）当玻璃反光，外圈 2px 白色细边 + 柔和外阴影，顶部有一道很细的白色高光弧。

手指拖动时泡实时跟手，带极轻的滞后（约 0.03 秒）。松手：泡在 0.35 秒内缩回 0.55 倍并淡出，被选中的那行恢复原样。

## 04 毛玻璃气泡（Glass Bubble）

做一个手机水平仪里的毛玻璃气泡。暗色页面 + 细网格背景。

页面上有两枚玻璃圆泡（直径约 152px 和 124px），随手机倾斜缓慢漂移。玻璃质感：半透明白色竖向渐变、外圈 1.8px 白色细线、左上角一块柔和高光、右下角一圈很淡的反光。

关键：两个泡靠近到边缘相交时，**不要各画各的圆**，而是用一个外切圆弧把两个圆连成一个连体轮廓（像水银合并成的哑铃形），中间没有接缝、没有描边；分开时同样用一个外切轮廓断开，不能突然跳变。整个过程连续、没有跳帧。

页面顶部显示当前角度（大号等宽整数 + 正负号），下面一行小字给 X / Y 两个分量，角度随两泡的距离实时变化，不要静止。底部一条细进度条跟着动。
