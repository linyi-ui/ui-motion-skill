# 滚动动效 · 4 个提示词

对应抖音视频：第08期 4个滚动动效

不想装 skill？直接复制下面的提示词发给 AI 编程工具（Claude Code / Codex / Cursor 等）就能用。

每个都附了"常见写法"（只说一句话时 AI 实测做出来的样子，每个测 3 份取多数），对比一下就知道提示词多管了什么。现在的 AI 一句话也会给滚动加点动画，但"什么时候触发、跟不跟手、几层速度"全靠它随便定。

---

## 01 依次浮现（Scroll Reveal）
常见写法：做一个旅行 App 首页，往下滑的时候内容要有出现动画 → 实测 3 份都会淡入上浮，但同一排的卡片一起冒出来、没有先后，到位时没有回弹，图片也不缩放

```
做一个旅行 App 首页，往下滑时卡片滑到眼前才一张张浮上来：每张卡片露出屏幕约 15% 时才触发，从下方约 40px 淡入上浮，同一行的卡片依次晚 70ms 出发（像发牌）；上浮到位时带一点点回弹，不要整页一起闪出来；卡片里的图片从放大 1.08 倍慢慢缩回原样；已经出现过的卡片往回滑不再重复播放；只动 transform 和 opacity，用 IntersectionObserver。
```

## 02 视差纵深（Parallax）
常见写法：做一个海岛度假官网首页，要有视差滚动效果 → 3 份都有视差，但基本只有背景比页面慢一点，其他层和页面一样快；电脑滚轮一格一跳，没有平滑；鼠标移动没有反应

```
做一个海岛度假官网首屏，往下滑时远近几层速度不一样，像坐车看窗外：画面分 4 层（天空、远山、海面、近处棕榈叶），越远动得越慢（天空 0.2 倍、远山 0.4 倍、海面 0.7 倍，近景 1.2 倍比页面还快）；大标题慢慢往上走并逐渐变淡；滚动用平滑跟随（每帧追上剩余距离的 12%），停手后再轻轻滑一小段才停，不要一格一格跳；鼠标移动时各层再跟着鼠标轻微错开；只用 transform + requestAnimationFrame；按 1440×900 电脑尺寸。
```

## 03 逐字点亮（Scroll Text Reveal）
常见写法：做一个产品介绍页，有一大段介绍文案，滚动时文字出现 → 3 份里 2 份是滑到那儿文字自己按时间播一遍淡入，不跟手指、手停了字还在播，也不钉住；只有 1 份做了跟滚动的逐字变色

```
做一个产品介绍页，一大段文案随着往下滑一个字一个字亮起来，像卡拉 OK 字幕：文字一开始是很淡的灰色（20% 不透明），滑动时按滚动进度从第一个字逐字变白，往回滑就逐字暗回去；正在亮的那个字轻轻上浮、从模糊变清晰；滑动期间这段文字钉在屏幕中间（sticky），整段亮完才继续往下走；关键词亮起时换成强调色；进度完全跟着手指，不要自己播放。
```

## 04 钉住换图（Sticky Scroll）
常见写法：做一个耳机产品发布页，左边文字右边产品图，往下滑介绍 4 个卖点 → 3 份里 2 份图片跟着文字一起滑走，每段一张图往下排；只有 1 份把图钉住了

```
做一个耳机产品发布页，右边产品图钉在原地，左边文字滑过一段就换一张图，像翻连环画：左边 4 段卖点文字正常往上滑，右边图片区钉住不动（sticky）；每段文字滑到屏幕中间时，右边交叉淡入换成对应的图，同时图片从 1.04 倍缩回原样、轻轻转一点角度；当前这段文字变亮，其他段变暗；右下角 4 个小圆点，高亮跟着滚动进度滑动；换图要顺，不要一下闪过去；按 1440×900 电脑尺寸。
```

---

小提示：最后可以加一句"深色主题，按 390×844 手机尺寸，开启系统减少动态效果时改成直接显示"。首屏内容不要藏起来等滚动，直接显示。

装了 skill 的话，直接说"用 ui-motion 做一个旅行 App 首页"即可，AI 会按动效库里的完整参数实现。
