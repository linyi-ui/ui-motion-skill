# 粒子动画 · 3 个提示词

对应抖音视频：第06期 3个粒子动画

不想装 skill？直接复制下面的提示词发给 AI 编程工具（Claude Code / Codex / Cursor 等）就能用。

每个都附了"常见写法"（只说一句话时 AI 实测做出来的样子），对比一下就知道提示词多管了什么。现在的 AI 只听一句话也能做出粒子，但彩纸往哪喷、消息怎么消失、手感多软，都是它随便定的，每次不一样。

---

## 01 撒花庆祝（Confetti）
常见写法：做一个打卡按钮，打卡成功后撒花 → 彩纸从按钮中间往四面八方炸开，正好落在按钮和数字上，把字挡住两秒

```
做一个打卡成功的撒花庆祝：点"打卡"按钮后，从按钮位置向上喷出约 100 片彩纸，有长条、圆片、小方块 3 种形状、5 种主题色；每片先快速冲上去，再被重力拉回来（发射角度在正上方左右 35° 内，速度随机）；下落时左右飘、绕自身翻面（翻到背面颜色变暗），越落越慢像有空气阻力；约 2.5 秒后各自逐渐淡出，不要同时消失；按钮先压一下再弹起，变成"已打卡 ✓"；用 canvas 画，保持 60 帧。
```

## 02 碎沙删除（Disintegrate）
常见写法：做一个聊天消息删除功能 → 消息淡出、缩一下就收起来了，没有碎开的感觉

```
做一个聊天消息删除时碎成沙子消失：长按消息选"删除"后，把这条气泡按像素拆成约 1500 粒小沙，每粒用气泡原来那个位置的颜色；从左往右依次散开（像一阵风扫过，约 0.8 秒扫完），每粒往右上方飘走，带一点随机抖动，边飘边变小、变淡，约 1 秒消失；散开的同时，原气泡从左往右被一点点擦掉，不要整条一起消失；删完后下面的消息平滑上移补位（约 300ms）。
```

## 03 粒子 Logo（Particle Logo）
常见写法：做一个官网首页，Logo 加粒子效果 → 这个一句话也能做出飞入和鼠标推开，但粒子多少、颜色、推多远、回不回弹每次都不一样；提示词把手感定死，每次都一样

```
做一个官网首页的粒子 Logo：用 canvas 把 Logo 文字采样成约 2000 个小圆点；页面打开时粒子从屏幕四周飞进来聚成 Logo（约 1.5 秒，先快后慢，每粒出发时间错开一点）；聚好后每粒轻轻呼吸浮动；鼠标划过时，附近的粒子被推开（半径约 80px，越近推得越远），鼠标离开后像被弹簧拉回原位，带一点点回弹；粒子用品牌渐变色。
```

---

小提示：粒子效果用在"值得庆祝 / 值得记住"的时刻才高级，一个页面最多放一处；手机上可以把粒子数量减半，再加一句"开启系统减少动态效果时，改成简单的淡入淡出"。

装了 skill 的话，直接说"用 ui-motion 给打卡成功加个撒花"即可，AI 会按动效库里的完整参数实现。
