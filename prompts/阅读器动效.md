# 阅读器动效（第38期）

手机 App 阅读器里 6 个像真书一样的翻页、划线、目录、字号与合书动效。每一条都能直接复制给 AI。

---

## 01 拖页角翻页（Page Flip）

```
做一个手机阅读器的翻页动效。用户手指从页面右下角按住往上拖，动作分两段：
第一段（0～0.5 秒）是起手：纸角跟着手指折起一个小三角，折角高光在边缘亮起，纸张有一点厚度感。
第二段是翻页：手指继续往左上拖，折线从右下角斜着向页面中部推进，页面被折线分成两块——折线外的那一块先被折成三角、卷起来，翻过来的背面显示镜像反过来的文字（浅一些），折线内那部分还是原来的正文。折线上始终有一道 2px 的柔和高光当纸的厚度，折线下方向下一页投一道随折线走的软阴影。下一页始终在底下铺着。
手指停在任意位置，页面就停在那个折叠角度；松手时如果已经翻过 80%，页面自动补完翻过去，露出下一页，过渡 0.3 秒并带一次很轻的过冲。整段用 ease-in-out，不要用旋转 3D 整体翻转，不要淡出淡入，纸是一直连着、被折过去的。
```

## 02 长按划线高亮（Highlight）

```
做一个手机阅读器的长按划线动效。用户手指按住正文某一行（长按 0.5 秒）不放：
1）按住的一瞬间，手指上方浮出一个圆形放大镜（直径约 150px），里面是按 2 倍放大、跟手指位置对齐的同一段文字，白色 2.5px 描边加柔和投影，从 0.8 倍弹到原大小。
2）按住后高亮块从按下的字开始出现，向右延伸到整行（约 320px），高度正好包住一行字（30px），圆角 2px，不透明度 42%，用强调色，纵向从 0.4 倍高度撑开到 1 倍。
3）手指向右拖动时高亮跟着增长，左右两端各出现一根 4px 竖条和一个小圆点抓柄，抓柄就跟着当前两端走。
4）松手：放大镜和抓柄淡出，底部弹出一个胶囊提示「已收藏这句」（对勾 + 文字），从下方 24px 带弹簧滑入，停 1 秒。
高亮出现和增长要跟手，不要一松手才出现。
```

## 03 划词菜单（Selection Menu）

```
做一个手机阅读器的划词菜单动效。用户长按选中一段文字（约两行）后松开，文字上覆盖一层 34% 不透明度的强调色高亮。
紧接着菜单从选中文字的中间偏上位置长出来：初始是一个 286px 宽、高度 0 的横条，0.5 秒内 height 从 0 长到 252px，同时从 0.94 倍放大到 1、从上方 14px 滑到原位，缓动用 ease-out；菜单是深色圆角卡片（圆角 14px、深色 97% 不透明、外圈 1px 浅描边、柔和投影），里面 5 行、每行 50px：复制 / 加书签 / 搜索书内 / 添加笔记 / 加入收藏，每行左侧一个线性图标、右侧文字，行间 1px 分隔线。
然后手指点「添加笔记」：这一行按压缩放到 0.97，菜单从底部收回（高度和透明度同时降到 0，0.3 秒），同时下方 40px 处长出一张笔记卡（334px 宽、高度 0→86px、圆角 12px、米白底、左侧 5px 强调色竖条，写着「笔记 / 想起那年站台上的风。」），带 10px 上浮。
菜单和笔记卡都要贴着那段文字，不要弹到屏幕中间。
```

## 04 章节目录滑出（Chapter Sheet）

```
做一个手机阅读器的章节目录抽屉动效。点右上角「目录」胶囊按钮，按钮先按压缩到 0.94 再弹回。
背后整页压暗 45% 黑色遮罩（0.3 秒淡入），抽屉从屏幕底部滑上来：390px 宽、560px 高、顶部圆角 26px、深色渐变底、顶部 1px 浅高光，从屏幕外 560px 处用一次带过冲的弹簧滑到距底部 0 的位置（约 0.75 秒，过冲约 6% 再回位）。
抽屉内容：顶部一条 44px 宽的把手、标题「目录」、副标题「共 24 章 · 已读 3 章」，下面 7 行章节（每行 56px，左边两位编号、中间章节名、下面一行时长），当前章那行底色淡淡高亮、左侧一根 3px 强调色竖条。
点第 4 行「窗边的书」：这一行先按压缩放 0.97，底色高亮亮起，0.4 秒后抽屉原路滑回屏幕底部（ease-in，不做过冲），遮罩同时淡出，背后正文亮度在 0.4 秒内降到 0.8 再回到 1，表示页面切换。
```

## 05 字号调节重排（Font Reflow）

```
做一个手机阅读器的字号调节动效。底部面板从屏幕下方 174px 处滑上来（0.4 秒 ease-out），面板顶部圆角 22px、深色渐变、顶部 1px 浅高光，里面「Aa」标题、一根 338px 的滑杆（右侧是强调色填充）、一个 24px 白色圆形滑钮，下方「小 / 标准 / 大」三个刻度字。
用户拖动滑钮向右：滑钮实时跟手，滑到哪强调色就填到哪，滑钮按住时放大到 1.12 倍；正文必须跟着实时变化，不是松手才变——字号从 15.5px 连续长到 22.5px，行高同步从 30px 长到 44px，段落跟着重新换行，但不要整段跳动，每一行按自己的宽度自然重排。
再往回拖：字号行高连续缩回 15.5px / 30px，正文重新排布回原样。整个变化用线性跟随，不要加缓动延迟，拖到哪个位置字号就是多少。
```

## 06 合书收进书架（Close to Shelf）

```
做一个手机阅读器合上书本的动效。书是摊开的两页（约 350×520px，左右各 175px，米白纸张）。
1）合书：右页先绕左边的书脊向里转，0.62 秒内 rotateY 从 0 到 176°；左页晚 0.1 秒跟上，0.68 秒内转 176°；两页同时转到 60% 进度时开始淡出，转完时露出一本合上的书脊（正面看到书脊那一面：暗红色渐变、竖排书名、左侧 5px 高光）。
2）飞回书架：书脊在 1.1 秒内整体缩小到 0.217 倍、向左上移动到书架第一格的位置（约 -133px、-142px）、同时轻微旋转 -8°，缓动 ease-in-out。
3）落位：到目标位置前 0.1 秒，书架第一格出现一个虚线空位描边，书落到位置后书架里的成品小书在 0.14 秒内渐显替代，落位时整体轻轻下沉一像素再回弹，阴影短暂加深。
整个过程书本不要整块消失，要有真实的合拢和归位感。
```
