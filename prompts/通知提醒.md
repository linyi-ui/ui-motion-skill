# 通知提醒动效 · 4 个提示词

对应抖音视频：4个通知动效，让App提醒不打扰

不想装 skill？直接复制下面的提示词发给 AI 编程工具（Claude Code / Codex / Cursor 等）就能用。

每个都附了"常见写法"，对比一下就知道差在哪：只说"给个提示"，AI 多半直接冒一条字或弹个框。

---

## 01 顶部消息横幅（In-app Banner）
常见写法：做一个聊天 App，收到新消息时在页面上提示 → 提示一闪就没（直接冒出来或淡入），推不走也点不进去，有的还弹个框挡住整页

```
做一个聊天 App 的顶部消息横幅，像有人从门口探头叫你一声：在别的页面时收到新消息，屏幕顶部从上往下滑出一张圆角卡片（头像 + 昵称 + 一行消息预览 + "刚刚"），带一点回弹（约 350ms），下面的页面不变暗、不被挡住操作；横幅停 3 秒自动往上收回，手指按住横幅时暂停计时；手指往上一推就跟手收走，点一下横幅放大过渡进入这条聊天；连续来消息时同一张横幅里文字往上滚动更新，不叠一堆；用一个按钮模拟收到消息；按 390×844 手机尺寸。
```

## 02 红点数字角标（Badge Count）
常见写法：做一个 App 底部导航栏，消息图标上显示未读数量 → 数字硬换没有翻动，变宽一下跳过去，点开后角标一下消失

```
做一个底部导航栏的未读数字角标，像计数器一格格往上翻：消息图标右上角一个红色圆角角标，来新消息时数字像老式翻牌一样往上滚到新数字（旧数字往上滑走、新数字从下面滑进来，约 250ms），角标同时轻轻弹一下（放大到 1.2 倍再回来）；数字变成两位数时角标平滑变宽成胶囊，超过 99 显示"99+"；点开消息页后角标缩小淡出消失，不要一下消失；用一个按钮模拟来一条消息；按 390×844 手机尺寸。
```

## 03 撤销提示条（Toast with Undo）
常见写法：做一个待办 App，删除任务后给个提示，可以撤销 → 删掉的那条直接没了、列表一跳；提示条没有倒计时线；连续删除多半只能救回最后一条

```
做一个待办 App 删除后的撤销提示条，像东西掉下去还能伸手接住：左滑或点删除后，这一条高度收起、下面的任务平滑往上补位；屏幕底部从下往上弹出一条深色圆角提示条"已删除 1 项任务"，右边一个强调色"撤销"按钮，提示条底部有一条细进度线从满到空走 4 秒；点撤销后那一条任务从原来的位置重新展开弹回来（高度展开 + 淡入），提示条往下收走；4 秒到了提示条自动收起，删除才算真的生效；连续删除时提示条原位更新文字"已删除 2 项任务"并重新计时；按 390×844 手机尺寸。
```

## 04 通知堆叠展开（Stacked Notifications）
常见写法：做一个手机通知中心页面，显示多条通知 → 分组、筛选都做得不错，但全是一长条平铺，满屏都是，没有叠起来

```
做一个通知中心的通知堆叠，像一摞扑克牌摊开：同一个 App 的多条通知叠成一摞，最上面一张完整显示，后面两张只露出底边、一张比一张略小略暗，右上角写"还有 4 条"；点一下这摞通知，后面的卡片依次往下滑开成完整列表（每张错开 50ms，带一点回弹），上方出现"收起"按钮；点收起时卡片反向叠回成一摞；单条通知往左滑可以划走，其他卡片平滑补位；按 390×844 手机尺寸。
```
