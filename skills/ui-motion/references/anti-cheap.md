- [ ] 启动不白屏：启动页和首页之间有衔接（Logo 放大开门、内容依次浮上来），不是盯着 Logo 干等再啪一下切走。
- [ ] 等待不盖页：点开详情、上传、发送时原页面保留可用，不用整页白屏转圈或遮罩挡住；进度看得见，先快后慢，不会自己走到 100%。
- [ ] 先给结果：缩略图、发出去的消息立刻出现，成功后再补状态（对勾、两个勾）；失败就近显示"点击重试"，不弹窗。
- [ ] 长等待有东西看：几秒以上的等待要有在变化的画面（波纹、小车、已等待秒数），结束时有收回、开过来、翻出来的衔接，不是文字一换就完事。
# 反廉价自检清单

交付前逐条检查。任何一条不合格，都要先修好再交付。

## 动效
- [ ] 没有 linear 曲线，也没有"瞬间出现/消失"的硬切，除非用户明确要求。
- [ ] 一组元素是依次出现的，不是同时蹦出来。
- [ ] 打开和关闭路径一致，关闭时没有直接消失。
- [ ] 没有超过 700ms 的动效，也没有为了炫而无限循环的装饰动画。
- [ ] 可点击元素有按下态，触屏上点了有反馈。
- [ ] 已处理 `prefers-reduced-motion`。
- [ ] 滚动和动画不卡顿：只动 transform 和 opacity，大面积模糊控制在 blur(24px) 以内。
- [ ] 手势交互：拖动时跟手，松手后有回弹/吸附/甩出过渡，没有"啪"一下跳回或直接消失；删除、排序后其他元素平滑补位，不是瞬间跳位。
- [ ] 页面切换：Tab、标签的选中指示器是流过去的，没有瞬移；新内容进来的方向和点击/滑动方向一致。
- [ ] 弹出层：底部弹窗能用手拖、能甩着关；出现时背后页面有退后（缩小、压暗），不是一动不动；拖动不会变成选中文字（拖动区域加 `user-select: none` 和 `touch-action: none`）。
- [ ] 吸顶标题：标题是缩小移动进顶栏，不是被内容盖住或突然换成另一个标题；松手不会停在半折叠状态。
- [ ] 加载：结构已知的页面没有用"白屏 + 转圈"；骨架屏和真实内容形状一致，内容到了是分块错开浮现，不是一下子全蹦出来。
- [ ] 图片：图片框提前固定宽高比，加载前后布局不跳；没有破图图标和突然砸下来的图。
- [ ] 加载更多：提前预加载，滚动不卡、位置不跳；有"没有更多了"和失败重试。
- [ ] AI 回复：发送后立刻有气泡和思考态；按词淡入不是逐字硬蹦；跟随滚动是平滑的，用户往上翻时不会被拽回底部。
- [ ] 输入框标签：没有拿 placeholder 当标签；用户打字后仍然看得到这一格在填什么（浮动标签或固定在上方的 label）。
- [ ] 校验时机：不是一打字就报红；停止输入约 400ms 或离开输入框才校验，改对后立刻变绿。
- [ ] 错误反馈：没有用 alert 弹窗报错，也不是只在底下冒一行红字；错误就近出现在输入框旁边，有动作 + 颜色 + 文字三重提示，出现时布局不跳。
- [ ] 验证码：不是一个长框挤数字；是独立格子、弹数字键盘、能粘贴和短信一键填入，填满自动提交。
- [ ] 粒子来源：粒子是从按钮 / 被删的元素 / Logo 本身来的，不是凭空满屏飘；沙粒用的是原元素的颜色。
- [ ] 粒子物理：有重力或阻力，先快后慢；彩纸会翻面、左右飘，不是一圈小圆点直线散开。
- [ ] 粒子退场：每个粒子各自淡出变小，不是整批同时消失；删除后下面的内容平滑补位，不是猛跳。
- [ ] 粒子分寸：一个页面最多一处粒子效果，所有粒子画在一个 canvas 上，不挡点击，减少动效时不放。
- [ ] 图表入场：不是所有柱子 / 整条线 / 整圈同时冒出来；按阅读顺序依次长出（柱子从左到右、折线一笔画出、圆环顺时针），数字跟着图形一起滚动，不是一开始就写死。
- [ ] 图表切换：切换周 / 月或筛选后，没有清空重画、所有柱子从 0 重新长；同一根柱子从旧高度变到新高度，刻度和数字一起平滑过渡。
- [ ] 图表点按：点柱子、圆环块后不只是变个颜色或出提示框；被选中的那一块有形变（压一下弹起、往外弹出、加粗），其他的退后变暗。
- [ ] 图表拖动：拖动看数时圆点吸在线上、数字连续滚动，不是一格一格跳；松手后提示框淡出、回到默认状态。
- [ ] 滚动浮现：不是一进页面全部内容一起闪出来，也不是同一行几张卡同时冒出；滑到才触发、依次出发，往回滑不重播。
- [ ] 滚动进度：视差、逐字点亮、钉住换图的进度跟着滚动位置走，手停就停、往回滑倒回去；不是滑到某处就"自己播一段动画"。
- [ ] 视差：远近层速度有明显差别（远慢近快，至少 3 层），不是只有背景图慢一点；电脑滚轮不是一格一跳。
- [ ] 钉住换图：图片区真的钉住，换图是交叉淡入而不是一下闪过去；当前段文字和进度圆点跟着高亮。
- [ ] 按钮反馈：点下去不只是变个色；复制、加购等结果反馈出现在按钮本身或有看得见的去向，没有用 alert 或另外弹个框代替。
- [ ] 图标切换：播放/暂停等成对图标是路径变形过去的，不是两个图标直接替换。
- [ ] 依次弹出：悬浮按钮的几个选项从按钮位置一个接一个弹出，收回时倒序；不是一下子全冒出来。
- [ ] 悬停：磁吸、填色等悬停效果只在电脑端生效，跟随是平滑的；按钮文字变化时宽度平滑过渡，不是一下跳。

## 视觉
- [ ] 没有纯色方块占位、灰色假图、"Lorem ipsum"。示例内容要像真实产品，有图标、真实文案和数字。
- [ ] 阴影是多层且柔和的，没有单层生硬黑影。
- [ ] 圆角统一成一套（如 12 / 20 / 28px），不随手乱写。
- [ ] 主强调色只有 1 个，最多加 1 个辅助色，没有彩虹配色。
- [ ] 文字层级清楚：标题、正文、辅助文字字号和透明度拉开，不是全部一样粗。
- [ ] 留白足够，元素没有挤在一起。
- [ ] 深色界面用的是深灰（如 #0f1013），不是纯黑 #000；浅色界面用的是浅灰底配白卡片。

## 可用性
- [ ] 手机上点击区域至少 44×44px。
- [ ] 文字和背景对比度够，浅灰字不要放在浅色背景上。
- [ ] 弹出层可以通过点遮罩、按 Esc 或点关闭按钮关闭。
